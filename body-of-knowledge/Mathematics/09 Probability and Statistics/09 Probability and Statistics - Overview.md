# Probability and Statistics — ความน่าจะเป็นและสถิติ

> **Category:** Advanced Mathematics (ม.4–ม.6, Sci-Math track)
> **Courses:** ค302 (ม.5) + ค303 (ม.6)
> **Covering:** Probability, Probability Distributions, Descriptive/Inferential Statistics

## Overview

Probability and Statistics at the advanced level transforms informal data sense into rigorous mathematical tools. Students learn counting principles and conditional probability (ม.5), then advance to formal probability distributions and statistical inference (ม.6) — essential preparation for university-level science, social science, and data science.

## Key Formulas

### Counting and Probability

| Concept | Formula |
|---|---|
| Permutations | P(n,r) = n!/(n−r)! |
| Combinations | C(n,r) = n!/(r!(n−r)!) |
| Conditional probability | P(A\|B) = P(A∩B)/P(B) |
| Bayes' theorem | P(A\|B) = P(B\|A)·P(A)/P(B) |
| Independent events | P(A∩B) = P(A)·P(B) |
| Mutually exclusive | P(A∪B) = P(A) + P(B) |

### Probability Distributions

| Distribution | Formula/Parameters | Use Case |
|---|---|---|
| **Binomial** | X ~ B(n, p) | n trials, success probability p |
| **Poisson** | X ~ P(λ) | Rare events, λ = mean rate |
| **Normal** | X ~ N(μ, σ²) | Natural phenomena, bell curve |
| **Z-score** | z = (x − μ)/σ | Standardizing for normal table lookup |

### Statistics

| Measure | Formula |
|---|---|
| Mean (population) | μ = Σxᵢ/N |
| Mean (sample) | x̄ = Σxᵢ/n |
| Variance | σ² = Σ(xᵢ−μ)²/N |
| Standard deviation | σ = √(σ²) |
| Correlation (Pearson) | r = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)² Σ(yᵢ−ȳ)²] |
| Confidence interval (95%) | x̄ ± 1.96·σ/√n |
