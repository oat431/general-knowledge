> **Category:** Advanced Biology (ม.6, ว323)
> **Covering:** Immune System, Reproduction, Behavior, Biotechnology, Bioethics

## Overview

The ม.6 biology curriculum brings together human physiology, cutting-edge biotechnology, and bioethics. Students learn how the immune system defends us, how life begins, and how we can now edit the code of life itself — raising profound ethical questions.

## Key Concepts

### Immune System

| Defense | Type | Mechanism |
|---|---|---|
| Skin, mucus | Physical barrier | Block entry |
| Macrophages | Innate | Engulf pathogens |
| B cells → Antibodies | Adaptive (humoral) | Tag pathogens for destruction |
| T cells | Adaptive (cellular) | Kill infected cells |
| Memory cells | Adaptive | Long-term immunity |

### Biotechnology Techniques

| Technique | Purpose |
|---|---|
| **PCR** (Polymerase Chain Reaction) | Amplify DNA — make millions of copies |
| **Gel electrophoresis** | Separate DNA fragments by size |
| **Recombinant DNA** | Combine DNA from different sources |
| **CRISPR-Cas9** | Gene editing — cut and modify specific DNA sequences |
| **Cloning** | Create genetically identical organisms |

### Bioethics Principles

| Principle | Question |
|---|---|
| **Autonomy** | Does the person consent? |
| **Beneficence** | Does it do good? |
| **Non-maleficence** | Does it avoid harm? |
| **Justice** | Is it fair and equitable? |
