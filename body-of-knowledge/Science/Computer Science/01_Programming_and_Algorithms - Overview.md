# Programming and Algorithms — การเขียนโปรแกรมและอัลกอริทึม

> **Category:** Computer Science (ว331–ว333, ม.4–ม.6)
> **Covering:** Computational Thinking, Data Representation, Boolean Logic, Programming, Functions, Algorithms, Data Structures, OOP

## Overview

Programming and Algorithms is the technical core of computer science. Students learn to think computationally, represent data in binary, code solutions in Python (typically), and analyze algorithmic efficiency. From basic loops to object-oriented design, this is where students become creators of software.

## Key Concepts

### Number Systems

| System | Base | Digits | Example |
|---|---|---|---|
| Binary | 2 | 0, 1 | 1010₂ = 10₁₀ |
| Octal | 8 | 0–7 | 12₈ = 10₁₀ |
| Decimal | 10 | 0–9 | 10₁₀ |
| Hexadecimal | 16 | 0–9, A–F | A₁₆ = 10₁₀ |

### Logic Gates

| Gate | Symbol | Output = 1 When... |
|---|---|---|
| AND | · | All inputs are 1 |
| OR | + | At least one input is 1 |
| NOT | ¯ | Input is 0 |
| NAND | ↑ | NOT (all inputs are 1) |
| NOR | ↓ | NOT (at least one input is 1) |
| XOR | ⊕ | Odd number of inputs are 1 |

### Big-O Complexity

| Complexity | Name | Example Algorithm |
|---|---|---|
| O(1) | Constant | Array access by index |
| O(log n) | Logarithmic | Binary search |
| O(n) | Linear | Linear search |
| O(n log n) | Linearithmic | Merge sort |
| O(n²) | Quadratic | Bubble sort, selection sort |
| O(2ⁿ) | Exponential | Brute-force password cracking |

### Python Concepts

| Concept | Example |
|---|---|
| Variable | `x = 5` |
| Conditional | `if x > 0: print("positive")` |
| Loop (for) | `for i in range(10):` |
| Function | `def add(a, b): return a + b` |
| List | `nums = [1, 2, 3]` |
| Dictionary | `d = {"key": "value"}` |
| Class | `class Dog: def __init__(self, name):` |
