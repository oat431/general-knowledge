## Key Concepts

### OSI Model (Simplified)

| Layer | Name | Function | Example |
|---|---|---|---|
| 7 | Application | User-facing | HTTP, FTP, SMTP |
| 4 | Transport | Reliable delivery | TCP, UDP |
| 3 | Network | Routing | IP |
| 2 | Data Link | Local delivery | Ethernet, Wi-Fi |
| 1 | Physical | Raw bits | Cables, radio waves |

### TCP/IP in One Sentence

> TCP breaks data into packets, numbers them, and reassembles them; IP addresses and routes each packet to its destination.

### SQL Basics

| Command | Purpose | Example |
|---|---|---|
| SELECT | Query data | `SELECT name, age FROM students WHERE age > 18;` |
| INSERT | Add data | `INSERT INTO students VALUES ('Somchai', 19);` |
| UPDATE | Modify data | `UPDATE students SET age = 20 WHERE name = 'Somchai';` |
| DELETE | Remove data | `DELETE FROM students WHERE name = 'Somchai';` |

### ER Diagram Basics

| Symbol | Meaning |
|---|---|
| Rectangle | Entity (table) |
| Oval | Attribute (column) |
| Diamond | Relationship |
| Line | Connection |

### AI Concepts

| Term | Meaning |
|---|---|
| **Machine Learning** | Algorithms that improve through experience |
| **Supervised Learning** | Training with labeled data |
| **Neural Network** | Layers of nodes inspired by brain neurons |
| **Deep Learning** | Neural networks with many layers |
| **Generative AI** | AI that creates content (text, images, code) |

### Digital Citizenship Principles

| Principle | Description |
|---|---|
| **Respect** | Treat others online as you would in person |
| **Protect** | Safeguard your privacy and data |
| **Verify** | Check information before sharing (anti-fake news) |
| **Credit** | Respect intellectual property and copyright |
| **Balance** | Maintain healthy screen time |

## Common Cyber Threats

| Threat | Description |
|---|---|
| **Phishing** | Fake emails/links to steal credentials |
| **Malware** | Viruses, worms, trojans, ransomware |
| **Social Engineering** | Manipulating people to reveal info |
| **DDoS** | Overwhelming a server with traffic |
