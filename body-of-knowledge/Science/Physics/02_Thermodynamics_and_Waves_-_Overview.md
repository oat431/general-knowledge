# Thermodynamics and Waves — อุณหพลศาสตร์และคลื่น

> **Category:** Advanced Physics (ม.4–ม.5, ว301–ว302)
> **Covering:** Oscillations, Waves, Sound, Heat, Thermodynamics, Fluid Mechanics
> **Foundation for:** Engineering, acoustics, meteorology

## Overview

This category bridges mechanics and modern physics. **Thermodynamics** studies heat, temperature, and energy transfer — essential for understanding engines, climate, and chemistry. **Waves and oscillations** explain sound, light, and eventually quantum mechanics. Together they describe how energy moves through the world.

## Key Formulas

### Oscillations & Waves

| Concept               | Formula                              |
| --------------------- | ------------------------------------ |
| SHM period (spring)   | $$T = 2\pi\sqrt{\frac{m}{k}}$$       |
| SHM period (pendulum) | $$T = 2\pi\sqrt{\frac{L}{g}}$$       |
| Wave speed            | $$v = f\lambda$$                     |
| Doppler effect        | $$f' = \frac{v \pm v_o}{v \mp v_s}$$ |

### Thermodynamics

| Concept           | Formula                         |
| ----------------- | ------------------------------- |
| Heat transfer     | $$Q = mc\Delta T$$              |
| Latent heat       | $$Q = mL$$                      |
| Ideal gas law     | $$PV = nRT$$                    |
| 1st Law           | $$\Delta U = Q - W$$            |
| Carnot efficiency | $$\eta = 1 - \frac{T_c}{T_h}$$ |
| Entropy change    | $$\Delta S = \frac{Q}{T}$$      |

### Fluid Mechanics

| Concept               | Formula                                                   |
| --------------------- | --------------------------------------------------------- |
| Pressure              | $$P = \frac{F}{A}$$                                       |
| Hydrostatic pressure  | $$P = \rho gh$$                                           |
| Buoyancy (Archimedes) | $$F_B = \rho_{	\text{fluid}} V_{	\text{displaced}} g$$    |
| Bernoulli             | $$P + 	\frac{1}{2}\rho v^2 + \rho gh = 	\text{constant}$$ |
| Continuity            | $$A_1 v_1 = A_2 v_2$$                                     |
