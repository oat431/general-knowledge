# Student Organizations — องค์กรนักเรียน

> *"Student organizations teach democracy by practice — students learn to represent, decide, and lead."*

Student organizations (องค์กรนักเรียน) include student councils, class representative systems, and school governance bodies where students participate in decision-making. They develop democratic participation, representation, responsibility, and leadership skills.

---

## 1 | Grade Band Breakdown

| Grade | Key Content |
|---|---|
| **ป.1–3** | Simple class roles (line leader, class helper), taking turns, responsibility |
| **ป.4–6** | Class representatives, simple student council, voting, school event participation |
| **ม.1–3** | Student council with officers, committees, event planning, representing student voice |
| **ม.4–6** | Advanced student governance, policy proposals, school improvement projects, mentoring |

---

## 2 | Key Concepts

| Concept | Thai | Description |
|---|---|---|
| Representation | การเป็นตัวแทน | Speaking and acting on behalf of classmates |
| Democracy | ประชาธิปไตย | Voting, fair process, respecting majority and minority |
| Responsibility | ความรับผิดชอบ | Fulfilling duties as a representative or officer |
| Leadership | ความเป็นผู้นำ | Guiding, planning, motivating others |
| Committee work | การทำงานเป็นคณะกรรมการ | Dividing tasks, collaborating on projects |
| Student voice | เสียงของนักเรียน | Expressing student concerns and ideas |

---

## 3 | Common Structures

| Structure | Thai | Description |
|---|---|---|
| Student Council | สภานักเรียน | Elected body representing students |
| Class Representative | ตัวแทนชั้น | Elected from each class to represent peers |
| Committee | คณะกรรมการ | Task-specific groups (events, discipline, activities) |
| President/VP | ประธาน/รองประธาน | Elected leaders of student body |
| Secretary/Treasurer | เลขานุการ/เหรัญญี | Administrative and financial roles |

## 5 | Real-World Examples

- **Student council election** — Campaign speeches, voting, democratic process
- **School event planning** — Sports day, Teacher's Day, graduation ceremonies
- **Student welfare committee** — Addressing student concerns and suggestions
- **Mentoring program** — ม.4–6 students mentoring ม.1 students
