# Conflict Resolution — การแก้ไขความขัดแย้ง

> *"Conflict is natural in any society — what matters is how we resolve it. Peaceful resolution builds stronger communities."*

Conflict Resolution teaches students how conflicts arise, how to resolve them peacefully, and how to participate constructively in civic life. From playground disputes to national protests, students learn the skills of negotiation, mediation, and democratic participation.

## 2 | Understanding Conflict

### Types of Conflict

| Type | Thai | Description | Example |
|---|---|---|---|
| **Interpersonal** | ความขัดแย้งระหว่างบุคคล | Between individuals | Arguments, bullying |
| **Intragroup** | ความขัดแย้งภายในกลุ่ม | Within a group | Team disagreements |
| **Intergroup** | ความขัดแย้งระหว่างกลุ่ม | Between groups | Rival schools, neighborhood disputes |
| **International** | ความขัดแย้งระหว่างประเทศ | Between nations | Border disputes, trade wars |
| **Structural** | ความขัดแย้งเชิงโครงสร้าง | Caused by systems | Inequality, discrimination |

### Causes of Conflict

| Cause | Thai | Description |
|---|---|---|
| **Competition for resources** | การแข่งขันเพื่อทรัพยากร | Land, water, money |
| **Misunderstanding** | ความเข้าใจผิด | Poor communication |
| **Different values** | ค่านิยมที่แตกต่าง | Cultural, religious, moral differences |
| **Power imbalance** | ความไม่สมดุลของอำนาจ | Inequality, oppression |
| **Injustice** | ความอยุติธรรม | Perceived unfairness |
| **Fear** | ความกลัว | Fear of the unknown, of change |

## 3 | Conflict Resolution Strategies

| Strategy | Thai | Description | When to Use |
|---|---|---|---|
| **Avoidance** | การหลีกเลี่ยง | Walking away from the conflict | Trivial issues, cooling-off period |
| **Accommodation** | การยอม | Giving in to the other party | Relationship more important than issue |
| **Competition** | การแข่งขัน | Winning at other's expense | Emergencies, safety issues |
| **Compromise** | การประนีประนอม | Each party gives up something | Time pressure, equal power |
| **Collaboration** | การร่วมมือ | Finding solution that satisfies both | Complex issues, important relationships |

### The Collaboration Process

| Step | Thai | Description |
|---|---|---|
| **1. Define the problem** | กำหนดปัญหา | Both sides agree on what the conflict is |
| **2. Share perspectives** | แบ่งปันมุมมอง | Each side explains their view |
| **3. Identify interests** | ระบุความสนใจ | What does each side really need? |
| **4. Generate options** | สร้างทางเลือก | Brainstorm possible solutions |
| **5. Evaluate options** | ประเมินทางเลือก | Which solutions meet both sides' needs? |
| **6. Agree on solution** | ตกลงในแนวทาง | Choose the best option together |
| **7. Implement** | ดำเนินการ | Put the agreement into action |
| **8. Follow up** | ติดตาม | Check if the solution is working |

## 4 | Negotiation (การเจรจาต่อรอง)

| Principle | Thai | Description |
|---|---|---|
| **Separate people from problems** | แยกคนออกจากปัญหา | Attack the problem, not the person |
| **Focus on interests, not positions** | มุ่งความสนใจ ไม่ใช่จุดยืน | Understand why, not just what |
| **Generate mutual gains** | สร้างผลประโยชน์ร่วม | Look for win-win solutions |
| **Use objective criteria** | ใช้เกณฑ์ที่เป็นกลาง | Base decisions on fair standards |
| **Active listening** | การฟังอย่างตั้งใจ | Understand before responding |

### Negotiation Skills

| Skill | Thai | Description |
|---|---|---|
| **I-statements** | ข้อความเชิง "ฉัน" | "I feel..." instead of "You always..." |
| **Active listening** | การฟังอย่างตั้งใจ | Paraphrasing, asking questions |
| **Empathy** | การเห็นอกเห็นใจ | Understanding the other's feelings |
| **Patience** | ความอดทน | Not rushing to conclusions |
| **Respect** | การเคารพ | Treating others with dignity |

## 5 | Mediation (การไกล่เกลี่ย)

| Role | Thai | Description |
|---|---|---|
| **Mediator** | คนกลาง | Neutral third party who facilitates discussion |
| **Parties** | คู่กรณี | People in conflict |
| **Agreement** | ข้อตกลง | Solution both parties accept |

### Mediation Process

| Step | Thai | Description |
|---|---|---|
| **1. Opening** | การเปิด | Mediator explains rules and process |
| **2. Storytelling** | การเล่าเรื่อง | Each side tells their story uninterrupted |
| **3. Issue identification** | การระบุประเด็น | List the issues to resolve |
| **4. Option generation** | การสร้างทางเลือก | Brainstorm solutions |
| **5. Agreement** | การตกลง | Write down agreed solutions |
| **6. Closing** | การปิด | Confirm understanding, set follow-up |

## 7 | Peaceful Protest (การประท้วงอย่างสันติ)

| Method | Thai | Description |
|---|---|---|
| **Demonstration** | การเดินขบวน | Peaceful march or gathering |
| **Petition** | การยื่นคำร้อง | Formal written request |
| **Boycott** | การคว่ำบาตร | Refusing to buy or participate |
| **Strike** | การหยุดงาน | Workers refusing to work |
| **Sit-in** | การนั่งประท้วง | Occupying a space peacefully |
| **Symbolic action** | การกระทำเชิงสัญลักษณ์ | Using symbols to convey message |

> In Thailand, the right to peaceful assembly is protected by the constitution, but must be exercised within legal boundaries.

## 8 | Restorative Justice (กระบวนการยุติธรรมเชิงสมานฉันท์)

| Aspect | Thai | Description |
|---|---|---|
| **Focus** | จุดเน้น | Repairing harm, not just punishing |
| **Parties** | ผู้เกี่ยวข้อง | Victim, offender, community |
| **Process** | กระบวนการ | Dialogue, accountability, restitution |
| **Outcome** | ผลลัพธ์ | Healing, reconciliation, reintegration |

### Restorative vs. Retributive Justice

| Aspect | Retributive (ลงโทษ) | Restorative (สมานฉันท์) |
|---|---|---|
| **Question** | What law was broken? | Who was harmed? |
| **Goal** | Punish the offender | Repair the harm |
| **Process** | Adversarial | Collaborative |
| **Outcome** | Punishment | Accountability + healing |
