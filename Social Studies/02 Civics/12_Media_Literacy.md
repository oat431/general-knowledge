# Media Literacy — การรู้เท่าทันสื่อ

> *"In the digital age, the ability to critically evaluate information is as important as the ability to read."*

Media Literacy teaches students how to access, analyze, evaluate, and create media responsibly. From traditional newspapers to social media, students learn to identify bias, verify information, and become responsible digital citizens.

## 3 | Media Literacy Skills

| Skill | Thai | Description |
|---|---|---|
| **Access** | การเข้าถึง | Finding and using media effectively |
| **Analyze** | การวิเคราะห์ | Breaking down media messages |
| **Evaluate** | การประเมิน | Judging quality, credibility, bias |
| **Create** | การสร้าง | Producing responsible media content |
| **Act** | การลงมือกระทำ | Using media for positive social change |

### Analyzing Media Messages

| Question | Thai | Purpose |
|---|---|---|
| **Who created this?** | ใครสร้างขึ้น | Identifying the source |
| **What is the purpose?** | วัตถุประสงค์คืออะไร | Inform, persuade, entertain? |
| **What techniques are used?** | ใช้เทคนิคอะไร | Emotional appeal, statistics, imagery |
| **What perspectives are missing?** | มีมุมมองใดขาดหายไป | Whose voice is absent? |
| **How might different people interpret this?** | คนต่างกันจะตีความอย่างไร | Considering audience diversity |

## 4 | Bias and Propaganda (อคติและโฆษณาชวนเชื่อ)

### Types of Bias

| Type | Thai | Description |
|---|---|---|
| **Confirmation bias** | อคติยืนยัน | Seeking information that confirms existing beliefs |
| **Selection bias** | อคติในการคัดเลือก | Choosing facts that support a narrative |
| **Framing bias** | อคติในการนำเสนอ | Presenting information in a particular light |
| **Omission bias** | อคติจากการละเว้น | Leaving out important information |
| **Commercial bias** | อคติเชิงพาณิชย์ | Influenced by advertisers or sponsors |

### Propaganda Techniques

| Technique | Thai | Description | Example |
|---|---|---|---|
| **Bandwagon** | โฆษณาชวนเชื่อแบบตามกระแส | "Everyone is doing it" | "Join millions of satisfied customers" |
| **Testimonial** | โฆษณาชวนเชื่อแบบอ้างอิง | Celebrity endorsement | Actor promoting a product |
| **Fear appeal** | โฆษณาชวนเชื่อแบบใช้ความกลัว | Creating fear to persuade | "If you don't buy X, bad things happen" |
| **Transfer** | โฆษณาชวนเชื่อแบบโอนย้าย | Associating with positive symbols | Using national flag in ads |
| **Repetition** | โฆษณาชวนเชื่อแบบซ้ำ | Repeating message until accepted | Slogans, jingles |
| **Emotional appeal** | โฆษณาชวนเชื่อทางอารมณ์ | Targeting emotions over logic | Sad music, heartwarming stories |

## 5 | Misinformation and Disinformation

| Type | Thai | Definition | Intent |
|---|---|---|---|
| **Misinformation** | ข้อมูลที่ผิดพลาด | False information shared without intent to harm | Unintentional |
| **Disinformation** | ข้อมูลบิดเบือน | False information shared deliberately to deceive | Intentional |
| **Malinformation** | ข้อมูลที่เป็นอันตราย | True information shared to cause harm | Intentional |

### How to Verify Information

| Step | Thai | Method |
|---|---|---|
| **1. Check the source** | ตรวจสอบแหล่งที่มา | Is it a reputable organization? |
| **2. Cross-reference** | เปรียบเทียบหลายแหล่ง | Do other sources confirm? |
| **3. Check the date** | ตรวจสอบวันที่ | Is it current or outdated? |
| **4. Check the author** | ตรวจสอบผู้เขียน | Who wrote it? What's their expertise? |
| **5. Check for bias** | ตรวจสอบอคติ | Is the language neutral or loaded? |
| **6. Use fact-checkers** | ใช้เว็บตรวจสอบข้อเท็จจริง | Thai fact-check organizations |

## 6 | Digital Citizenship (ความเป็นพลเมืองดิจิทัล)

| Principle | Thai | Description |
|---|---|---|
| **Digital etiquette** | มารยาทออนไลน์ | Respectful online behavior |
| **Digital literacy** | ทักษะดิจิทัล | Using technology effectively |
| **Digital safety** | ความปลอดภัยออนไลน์ | Protecting personal information |
| **Digital responsibility** | ความรับผิดชอบดิจิทัล | Thinking before sharing |
| **Digital rights** | สิทธิดิจิทัล | Privacy, access, freedom of expression |
| **Digital health** | สุขภาพดิจิทัล | Managing screen time, mental health |

### Online Safety Rules

| Rule | Thai | Description |
|---|---|---|
| **Protect personal info** | ปกป้องข้อมูลส่วนตัว | Don't share address, phone, ID number |
| **Strong passwords** | รหัสผ่านที่แข็งแรง | Use unique, complex passwords |
| **Think before posting** | คิดก่อนโพสต์ | Content is permanent once shared |
| **Report cyberbullying** | รายงานการกลั่นแกล้ง | Tell a trusted adult |
| **Verify before sharing** | ตรวจสอบก่อนแชร์ | Don't spread misinformation |

## 7 | Media and Society

### Media Influence on Behavior

| Area | Thai | Influence |
|---|---|---|
| **Body image** | ภาพลักษณ์ร่างกาย | Beauty standards from media |
| **Consumer behavior** | พฤติกรรมการบริโภค | Advertising drives purchases |
| **Political opinions** | ความคิดเห็นทางการเมือง | News framing shapes views |
| **Social norms** | บรรทัดฐานทางสังคม | Media normalizes behaviors |
| **Fear and anxiety** | ความกลัวและความวิตกกังวล | Crime reporting, disaster coverage |

### Media Ownership and Control

| Aspect | Thai | Description |
|---|---|---|
| **Concentration** | การกระจุกตัว | Few owners control many outlets |
| **Government influence** | อิทธิพลของรัฐบาล | State media, regulation |
| **Corporate influence** | อิทธิพลของธุรกิจ | Advertising pressure |
| **Self-censorship** | การเซ็นเซอร์ตนเอง | Avoiding controversial topics |
