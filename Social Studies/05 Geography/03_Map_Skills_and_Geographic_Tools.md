# Map Skills and Geographic Tools — ทักษะแผนที่และเครื่องมือทางภูมิศาสตร์

> *"Maps are the language of geography — they help us understand where things are, why they are there, and how they relate to each other."*

Map Skills teaches students to read, interpret, and create maps. From simple classroom maps in primary school to topographic maps and GIS in secondary, students develop spatial literacy — the ability to think about the world in geographic terms.

## 2 | Map Elements

| Element | Thai | Description |
|---|---|---|
| **Title** | ชื่อแผนที่ | What the map shows |
| **Legend** | สัญลักษณ์ | Key to map symbols |
| **Scale** | สัดส่วน | Ratio of map distance to real distance |
| **Compass rose** | เข็มทิศ | Direction indicator (N, S, E, W) |
| **Grid** | ตารางกริด | Reference system for location |

---

## 3 | Scale (สัดส่วน)

| Type | Description | Example |
|---|---|---|
| **Statement scale** | Written as ratio | "1 cm represents 1 km" |
| **Representative fraction** | Written as fraction | 1:100,000 |
| **Linear scale** | Drawn as line | Bar marked with distances |

**Example:** Scale 1:50,000 means 1 cm on map = 50,000 cm (500 m) in reality.

---

## 4 | Types of Maps

| Type | Thai | Purpose |
|---|---|---|
| **Physical map** | แผนที่กายภาพ | Shows landforms, water bodies |
| **Political map** | แผนที่การเมือง | Shows countries, cities, boundaries |
| **Thematic map** | แผนที่เฉพาะเรื่อง | Shows specific data (population, climate) |
| **Topographic map** | แผนที่ภูมิประเทศ | Shows elevation with contour lines |

| System | Thai | Description |

| **Longitude** | ลองจิจูด | Distance east/west of Prime Meridian (0°–180°) |

## 6 | Contour Lines (เส้นชั้นความสูง)

| Feature | Description |
|---|---|
| **Close together** | Steep slope |
| **Far apart** | Gentle slope |
| **Concentric circles** | Hill/mountain peak |
| **V-shape pointing uphill** | Valley/river |
| **V-shape pointing downhill** | Ridge/spur |

## 10 | Upper Secondary (ม.4-6): Advanced GIS and Remote Sensing

### GIS Applications

| Application | Thai | Description |
|---|---|---|
| **Urban planning** | การวางผังเมือง | Land use zoning, growth monitoring |
| **Disaster management** | การจัดการภัยพิบัติ | Flood modeling, evacuation routing |
| **Agriculture** | เกษตรกรรม | Crop monitoring, precision farming |
| **Transportation** | การคมนาคม | Route optimization, traffic analysis |
| **Epidemiology** | ระบาดวิทยา | Disease mapping, spread prediction |
| **Business** | ธุรกิจ | Site selection, market analysis |
| **Conservation** | การอนุรักษ์ | Habitat mapping, species tracking |

### Remote Sensing (การรับรู้จากระยะไกล)

| Platform | Thai | Resolution | Use |
|---|---|---|---|
| **Landsat** | แลนด์แซต | 30m | Land cover, free access |
| **Sentinel** | เซนติเนล | 10-20m | European, free access |
| **WorldView** | เวิลด์วิว | 0.3-0.5m | High-resolution commercial |
| **MODIS** | โมดิส | 250m-1km | Daily global monitoring |
| **Thai Earth Observation** | ดาวเทียมไทย | 2-20m | THEOS (2008) |

### Digital Cartography

| Trend | Thai | Description |
|---|---|---|
| **Web mapping** | แผนที่บนเว็บ | Google Maps, OpenStreetMap |
| **3D visualization** | การมองเห็นสามมิติ | Google Earth, Cesium |
| **Interactive maps** | แผนที่โต้ตอบ | Data dashboards |
| **Story maps** | แผนที่เล่าเรื่อง | Narrative + geographic data |
| **Crowdsourced mapping** | แผนที่โดยมวลชน | OpenStreetMap, WikiMapping |
