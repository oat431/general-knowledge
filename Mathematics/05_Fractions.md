# Fractions — เศษส่วน

> *"Fractions are not broken numbers — they are numbers in their own right, fundamental to understanding division, ratio, proportion, and the rational number system."*

Understanding fractions as parts of a whole, as division, as ratios, and as numbers. Students progress from concrete fraction models using area and set representations to performing all operations with proper fractions, improper fractions, and mixed numbers. Fractions are the gateway to rational numbers, percentages, ratios, and algebra.

## 3 | Key Concepts & Operations

### 3.1 Fraction Definition

A fraction is written as **a/b** where:
- **a** = numerator (ตัวเศษ) — how many parts you have
- **b** = denominator (ตัวส่วน) — how many equal parts the whole is divided into
- **b ≠ 0** (division by zero is undefined)

A fraction represents:
- **Part of a whole:** 3/4 of a pizza
- **Division:** 3 ÷ 4 = 3/4
- **Ratio:** 3 : 4

### 3.2 Types of Fractions

| Type | Definition | Example |
|---|---|---|
| **Proper (เศษส่วนแท้)** | Numerator < Denominator | 3/4, 2/5 |
| **Improper (เศษเกิน)** | Numerator ≥ Denominator | 5/3, 7/4 |
| **Mixed number (จำนวนคละ)** | Whole number + proper fraction | 2 1/3, 5 3/4 |
| **Unit fraction** | Numerator = 1 | 1/2, 1/3, 1/10 |

### 3.3 Equivalent Fractions

Fractions that represent the same value:

> **Rule:** Multiply or divide both numerator and denominator by the same non-zero number.

```
1/2 = 2/4 = 3/6 = 4/8 = 5/10 = 50/100 = ...

General: a/b = (a×k)/(b×k) = (a÷k)/(b÷k)   for k ≠ 0
```

### 3.4 Simplifying Fractions

Divide numerator and denominator by their GCD:

> 18/24 → GCD(18,24) = 6 → (18÷6)/(24÷6) = **3/4**

### 3.5 Converting Between Mixed Numbers and Improper Fractions

**Mixed → Improper:** Multiply whole number by denominator, add numerator.

> 3 2/5 = (3 × 5 + 2)/5 = **17/5**

**Improper → Mixed:** Divide numerator by denominator. Quotient = whole part, remainder = numerator of fractional part.

> 17 ÷ 5 = 3 remainder 2 → **3 2/5**

---

### 3.6 Operations with Fractions

#### Addition and Subtraction

**Same denominator:** Simply add/subtract the numerators.

> 2/7 + 3/7 = **5/7**

**Different denominators — find LCD first:**

> 2/3 + 3/4
> = (2×4)/(3×4) + (3×3)/(4×3)
> = 8/12 + 9/12
> = 17/12
> = **1 5/12**

#### Multiplication

Multiply numerators, multiply denominators. Tip: cancel common factors first!

> 3/5 × 10/9 = (3×10)/(5×9) = 30/45 = **2/3**

#### Division

Multiply by the reciprocal (กลับเศษเป็นส่วน):

> 5/6 ÷ 2/3 = 5/6 × 3/2 = 15/12 = 5/4 = **1 1/4**

### 3.7 Comparing Fractions (All Positive)

**Method: Cross-multiplication (การคูณไขว้)**

> a/b > c/d  if and only if  a × d > b × c

**Example:** Compare 5/8 and 3/5:
- 5 × 5 = 25
- 8 × 3 = 24
- 25 > 24, so **5/8 > 3/5** ✓

## 4 | Common Problem Types

### Type 1: Simplifying
> Simplify 18/24 to lowest terms.

GCD(18, 24) = 6. (18÷6)/(24÷6) = **3/4**

### Type 2: Converting Forms
> Convert 5 2/3 to an improper fraction.

(5 × 3 + 2)/3 = **17/3**

### Type 3: Addition with Different Denominators
> Add: 2/3 + 3/4

LCM(3, 4) = 12. 2/3 = 8/12, 3/4 = 9/12. 8/12 + 9/12 = 17/12 = **1 5/12**

### Type 4: Multiplication
> Multiply: 3/5 × 10/9

(3×10)/(5×9) = 30/45 = **2/3**

### Type 5: Division
> Divide: 5/6 ÷ 2/3

5/6 × 3/2 = 15/12 = 5/4 = **1 1/4**

### Type 6: Fraction of a Quantity
> Find 3/4 of 200 Baht.

3/4 × 200 = **150 Baht**
