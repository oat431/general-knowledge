# Mathematical Processes — กระบวนการทางคณิตศาสตร์

> *"Mathematics is not a spectator sport. The processes of problem-solving, reasoning, communication, and representation are the skills that make mathematical knowledge useful — they are what transforms knowing into doing."*

Mathematical processes are the cross-cutting skills woven throughout all other mathematics topics. They include problem-solving strategies, reasoning and proof, mathematical communication, making connections, and using multiple representations. These are not standalone topics but the "how" of doing mathematics at every level.

## 1 | Grade Band Breakdown

### ป.1–3 (Grades 1–3)

| Skill | Key Development |
|---|---|
| **Problem solving** | Using concrete objects; drawing pictures; acting out problems; guess-and-check |
| **Reasoning** | Explaining "why" in simple terms; recognizing patterns |
| **Communication** | Using mathematical words (more than, less than, equal); showing work with drawings |
| **Connections** | Math in daily life (counting money, telling time, measuring ingredients) |
| **Representation** | Using objects, drawings, numbers to represent problems |

### ป.4–6 (Grades 4–6)

| Skill | Key Development |
|---|---|
| **Problem solving** | Polya's steps: understand → plan → solve → check; multiple strategies (working backward, making a table, drawing diagrams) |
| **Reasoning** | Justifying solutions; finding patterns and making conjectures; recognizing when answers make sense |
| **Communication** | Writing step-by-step solutions; using precise mathematical language; presenting findings |
| **Connections** | Connecting math topics (fractions ↔ decimals ↔ percents); applying math to science |
| **Representation** | Using tables, graphs, equations, and diagrams to model situations |

### ม.1–3 (Grades 7–9)

| Skill | Key Development |
|---|---|
| **Problem solving** | Complex multi-step problems; mathematical modeling; choosing optimal strategies |
| **Reasoning** | Deductive reasoning (general → specific); inductive reasoning (patterns → generalization); constructing simple proofs |
| **Communication** | Writing formal mathematical arguments; using proper notation; critiquing others' reasoning |
| **Connections** | Connecting algebra ↔ geometry ↔ statistics; recognizing math in real-world systems |
| **Representation** | Multiple representations of functions (table, graph, equation, verbal); choosing best representation |

## 2 | Polya's Problem-Solving Framework (ขั้นตอนการแก้ปัญหาของโพลยา)

| Stage | Thai | Actions |
|---|---|---|
| **1. Understand** | ทำความเข้าใจปัญหา | Read carefully; identify what's given and what's asked; restate in own words |
| **2. Plan** | วางแผนการแก้ปัญหา | Choose strategy: draw a picture, make a table, work backward, guess & check, write an equation, look for a pattern, solve a simpler problem |
| **3. Solve** | ดำเนินการตามแผน | Execute the plan; show all steps clearly |
| **4. Check** | ตรวจสอบผล | Does the answer make sense? Is there another way to verify? |

## 3 | Problem-Solving Strategies

| Strategy | When to Use | Example |
|---|---|---|
| **Draw a picture** | Geometric/spatial problems | "A rectangular garden..." |
| **Make a table** | Pattern recognition / organized listing | "How many handshakes?" |
| **Work backward** | Known final result, unknown start | "After spending half, I have..." |
| **Guess and check** | Limited possibilities | "Find two numbers whose sum is..." |
| **Write an equation** | Algebraic relationships | "Three more than twice a number..." |
| **Look for a pattern** | Sequences and predictions | "What is the 10th term?" |
| **Solve a simpler problem** | Large scale / complex | "Use smaller numbers first" |
| **Act it out** | Concrete / sequential | "Three people crossing a bridge..." |

## 4 | Types of Reasoning

### 4.1 Inductive Reasoning (อุปนัย)
**Pattern → Generalization**

> Observe: 1+3=4, 1+3+5=9, 1+3+5+7=16. Conjecture: sum of first n odd numbers = n².

### 4.2 Deductive Reasoning (นิรนัย)
**General rule → Specific conclusion**

> All squares have 4 right angles. Shape X is a square. Therefore, X has 4 right angles.

### 4.3 Proof by Contradiction (การพิสูจน์โดยข้อขัดแย้ง) — ม.3
Assume the opposite and show it leads to a contradiction.

> **Prove √2 is irrational:**
> Assume √2 = a/b (in lowest terms). Then 2 = a²/b² → a² = 2b². So a² is even, thus a is even. Let a = 2k. Then 4k² = 2b² → b² = 2k², so b is also even. This contradicts our assumption that a/b was in lowest terms. ∴ √2 is irrational.

## 5 | Mathematical Communication

Good mathematical communication:

| Do | Avoid |
|---|---|
| Show steps clearly | Skipping steps "because it's obvious" |
| Label variables and units | Missing or inconsistent units |
| Use proper notation (=, ≈, ∴, ∵) | Non-standard abbreviations |
| State assumptions | Assuming the reader knows |
| Conclude with a clear answer | Leaving answer ambiguous |

## 6 | Multiple Representations

| Representation | Best For |
|---|---|
| **Concrete (objects)** | Early learners; building intuition |
| **Pictorial (diagrams)** | Spatial reasoning; visualizing |
| **Tabular (tables)** | Organizing data; patterns |
| **Graphical (graphs)** | Trends; relationships |
| **Symbolic (equations)** | Precision; generalization |
| **Verbal (words)** | Real-world context |

**Example — Linear Function y = 2x + 1:**

| Representation | Form |
|---|---|
| Table | (0,1), (1,3), (2,5), (3,7) |
| Graph | Straight line through (0,1) with slope 2 |
| Equation | y = 2x + 1 |
| Verbal | "The output is one more than twice the input" |
