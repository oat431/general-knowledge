# Fractions — เศษส่วน

> *"Fractions are not broken numbers — they are numbers in their own right, fundamental to understanding division, ratio, proportion, and the rational number system."*

Understanding fractions as parts of a whole, as division, as ratios, and as numbers. Students progress from concrete fraction models using area and set representations to performing all operations with proper fractions, improper fractions, and mixed numbers. Fractions are the gateway to rational numbers, percentages, ratios, and algebra.

## 3 | Key Concepts & Operations

### 3.1 Fraction Definition

$$\frac{a}{b} \quad \text{where } a = \text{numerator}, \ b = \text{denominator}, \ b \neq 0$$

A fraction represents:
- **Part of a whole:** $$\frac{3}{4}$$ of a pizza
- **Division:** $$3 \div 4 = \frac{3}{4}$$
- **Ratio:** $$3 : 4$$

### 3.2 Types of Fractions

| Type | Definition | Example |
|---|---|---|
| **Proper (เศษส่วนแท้)** | Numerator < Denominator | $$\frac{3}{4}, \frac{2}{5}$$ |
| **Improper (เศษเกิน)** | Numerator ≥ Denominator | $$\frac{5}{3}, \frac{7}{4}$$ |
| **Mixed number (จำนวนคละ)** | Whole number + proper fraction | $$2\frac{1}{3}, 5\frac{3}{4}$$ |
| **Unit fraction** | Numerator = 1 | $$\frac{1}{2}, \frac{1}{3}, \frac{1}{10}$$ |

### 3.3 Equivalent Fractions

$$\frac{a}{b} = \frac{a \times k}{b \times k} = \frac{a \div k}{b \div k} \quad \text{for } k \neq 0$$

$$\frac{1}{2} = \frac{2}{4} = \frac{3}{6} = \frac{4}{8} = \frac{5}{10} = \ldots$$

### 3.4 Simplifying Fractions

Divide numerator and denominator by their GCD:

$$\frac{18}{24} = \frac{18 \div 6}{24 \div 6} = \frac{3}{4}$$

### 3.5 Converting Between Mixed Numbers and Improper Fractions

**Mixed → Improper:**

$$N\frac{r}{d} = \frac{N \times d + r}{d}$$

**Example:** $$3\frac{2}{5} = \frac{3 \times 5 + 2}{5} = \frac{17}{5}$$

**Improper → Mixed:** Divide numerator by denominator. Quotient = whole part, remainder = numerator of fractional part.

**Example:** $$17 \div 5 = 3 \text{ remainder } 2 \rightarrow 3\frac{2}{5}$$

---

### 3.6 Operations with Fractions

#### Addition and Subtraction

**Same denominator:**

$$\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}$$

**Different denominators — find LCD first:**

$$\frac{2}{3} + \frac{3}{4} = \frac{2 \times 4}{3 \times 4} + \frac{3 \times 3}{4 \times 3} = \frac{8}{12} + \frac{9}{12} = \frac{17}{12} = 1\frac{5}{12}$$

#### Multiplication

$$\frac{a}{b} \times \frac{c}{d} = \frac{a \times c}{b \times d}$$

**Tip:** Cancel common factors before multiplying to simplify:

$$\frac{3}{5} \times \frac{10}{9} = \frac{\cancel{3}^1}{\cancel{5}_1} \times \frac{\cancel{10}^2}{\cancel{9}_3} = \frac{2}{3}$$

#### Division

$$\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c} = \frac{a \times d}{b \times c}$$

**Rule:** Multiply by the reciprocal (กลับเศษเป็นส่วน):

$$\frac{5}{6} \div \frac{2}{3} = \frac{5}{6} \times \frac{3}{2} = \frac{15}{12} = \frac{5}{4} = 1\frac{1}{4}$$

### 3.7 Comparing Fractions (All Positive)

**Method: Cross-multiplication (การคูณไขว้)**

$$\frac{a}{b} > \frac{c}{d} \quad \text{if and only if} \quad a \times d > b \times c$$

**Example:** Compare $$\frac{5}{8}$$ and $$\frac{3}{5}$$:
- $$5 \times 5 = 25$$
- $$8 \times 3 = 24$$
- $$25 > 24$$, so $$\frac{5}{8} > \frac{3}{5}$$ ✓

## 4 | Common Problem Types

### Type 1: Simplifying
> Simplify $$\frac{18}{24}$$ to lowest terms.

$$\text{GCD}(18, 24) = 6. \quad \frac{18 \div 6}{24 \div 6} = \frac{3}{4}$$

### Type 2: Converting Forms
> Convert $$5\frac{2}{3}$$ to an improper fraction.

$$\frac{5 \times 3 + 2}{3} = \frac{17}{3}$$

### Type 3: Addition with Different Denominators
> Add: $$\frac{2}{3} + \frac{3}{4}$$

$$\text{LCM}(3, 4) = 12$$
$$\frac{2}{3} = \frac{8}{12}, \quad \frac{3}{4} = \frac{9}{12}, \quad \frac{8}{12} + \frac{9}{12} = \frac{17}{12} = 1\frac{5}{12}$$

### Type 4: Multiplication
> Multiply: $$\frac{3}{5} \times \frac{10}{9}$$

$$\frac{3 \times 10}{5 \times 9} = \frac{30}{45} = \frac{2}{3}$$

### Type 5: Division
> Divide: $$\frac{5}{6} \div \frac{2}{3}$$

$$\frac{5}{6} \times \frac{3}{2} = \frac{15}{12} = \frac{5}{4} = 1\frac{1}{4}$$

### Type 6: Fraction of a Quantity
> Find $$\frac{3}{4}$$ of 200 Baht.

$$\frac{3}{4} \times 200 = 150 \text{ Baht}$$
