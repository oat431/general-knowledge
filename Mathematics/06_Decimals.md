# Decimals — ทศนิยม

> *"Decimals are simply fractions with denominators of 10, 100, 1000... — an elegant extension of the base-10 place value system that makes computation with fractional quantities as natural as working with whole numbers."*

Decimals extend the base-10 place value system to represent numbers smaller than one. Students learn to read, write, compare, and perform all operations with decimals, bridging the gap between whole numbers and the rational number system.

## 3 | Key Concepts

### 3.1 Decimal Place Value

Digits to the right of the decimal point represent fractions with denominators that are powers of 10:

$$3.456 = 3 + \rac{4}{10} + \rac{5}{100} + \rac{6}{1000}$$

```
    3  .  4  5  6
    ↑     ↑  ↑  ↑
  ones   |  |  |
       tenths |  |
         hundredths |
             thousandths
```

### 3.2 Fraction ↔ Decimal Conversion

**Fraction → Decimal:** Divide numerator by denominator.

$$\rac{7}{8} = 7 \div 8 = 0.875$$

**Decimal → Fraction:** Write as fraction with denominator as power of 10, then simplify.

$$0.75 = \rac{75}{100} = \rac{3}{4}$$

### 3.3 Terminating vs Repeating Decimals

A fraction a/b (in lowest terms) produces:
- A **terminating decimal** if b's only prime factors are 2 and 5
- A **repeating decimal** otherwise

| Fraction | Decimal | Type |
|---|---|---|
| 1/2 = 0.5 | Terminates | b = 2 (only factor 2) ✓ |
| 1/3 = 0.333... | Repeats | b = 3 (has factor 3) ✗ |
| 1/4 = 0.25 | Terminates | b = 4 = 2² ✓ |
| 1/5 = 0.2 | Terminates | b = 5 ✓ |
| 1/6 = 0.1666... | Repeats | b = 6 = 2×3 ✗ |
| 1/8 = 0.125 | Terminates | b = 8 = 2³ ✓ |

**Repeating decimal notation:** $$0.\overline{3}$$ or 0.3̄ for 0.333...

### 3.4 Decimal Operations

#### Addition / Subtraction
**Rule:** Align decimal points; add/subtract column by column.

```
  23.450
+  6.789
--------
  30.239
```

#### Multiplication
**Rule:** Multiply as whole numbers; the product has **(m + n)** decimal places (where multipliers have m and n places).

$$0.3 \	imes 0.04 = 0.012$$
$$(1 \	ext{ place}) + (2 \	ext{ places}) = 3 \	ext{ places}$$

#### Division by a Decimal
**Rule:** Move decimal point in BOTH dividend and divisor to make the divisor a whole number, then divide.

$$4.5 \div 0.03 = 450 \div 3 = 150$$

## 4 | Common Problem Types

### Type 1: Reading Thai Decimals
> Write "สามจุดหนึ่งสี่หก" in digits.

**Answer:** 3.146

### Type 2: Fraction to Decimal
> Convert 7/8 to a decimal.

$$7 \div 8 = 0.875$$

### Type 3: Decimal to Fraction
> Convert 0.625 to a fraction in lowest terms.

$$0.625 = \rac{625}{1000} = \rac{625 \div 125}{1000 \div 125} = \rac{5}{8}$$

### Type 4: Decimal Addition
> 23.45 + 6.789 = ?

**Answer:** 30.239

### Type 5: Decimal Multiplication
> 4.5 × 0.12 = ?

45 × 12 = 540. (1 + 2 = 3 decimal places) → **0.54**

### Type 6: Decimal Division
> 8.4 ÷ 0.07 = ?

Move decimal 2 places: 840 ÷ 7 = **120**
