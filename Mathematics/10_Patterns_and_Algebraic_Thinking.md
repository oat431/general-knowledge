# Patterns and Algebraic Thinking — รูปแบบและความสัมพันธ์

> *"All of algebra begins with a simple observation: patterns exist. First we notice them. Then we describe them. Finally, we generalize them — and mathematics becomes a language for expressing relationships."*

Patterns and algebraic thinking form the bridge from arithmetic to algebra. Students progress from recognizing repeating patterns in early primary to writing algebraic expressions, equations, and analyzing functions in lower secondary. This is where mathematics shifts from computing specific answers to describing general relationships.

## 3 | Key Concepts

### 3.1 Types of Patterns

| Type | Example | Rule |
|---|---|---|
| **Repeating** | 🟡🔵🟡🔵🟡🔵... | AB pattern, repeats every 2 |
| **Growing (arithmetic)** | 3, 7, 11, 15, 19... | Add 4 each time |
| **Growing (geometric)** | 2, 6, 18, 54... | Multiply by 3 each time |
| **Fibonacci-like** | 1, 1, 2, 3, 5, 8... | Add previous two terms |
| **Square numbers** | 1, 4, 9, 16, 25... | n² |
| **Triangular numbers** | 1, 3, 6, 10, 15... | n(n+1)/2 |

### 3.2 From Pattern to Rule

**Find the nth term of: 3, 7, 11, 15, 19...**

| Step | Action |
|---|---|
| 1 | Recognize it's arithmetic (constant difference) |
| 2 | Common difference d = 4 |
| 3 | Term n = first term + (n−1) × d |
| 4 | $$a_n = 3 + (n-1) \	imes 4 = 4n - 1$$ |

Verify: n=1 → 3 ✓, n=2 → 7 ✓, n=3 → 11 ✓

### 3.3 From Arithmetic to Algebra

| Arithmetic (concrete) | Algebra (generalized) |
|---|---|
| 3 + 5 = 8 | a + b = c |
| 7 × 9 = 63 | x × y = z |
| Area = length × width | A = l × w |
| Rectangle perimeter = 2l + 2w | P = 2(l + w) |

### 3.4 Algebraic Expressions (นิพจน์)

| Expression | Meaning |
|---|---|
| 3x | 3 times x |
| x + 5 | x increased by 5 |
| 2x − 3 | Twice x, minus 3 |
| x² | x multiplied by itself |
| (x + 2)(x − 3) | Product of (x+2) and (x−3) |
| 3(x + 4) | 3 times the quantity (x+4) |

**Simplifying expressions:**
$$2x + 3x = 5x$$
$$3(2x + 1) = 6x + 3$$
$$(x + 2)(x + 3) = x^2 + 5x + 6$$

### 3.5 Functions as Input/Output Machines

```
Input (x) → [ f(x) = 2x + 1 ] → Output (y)
```

| Input (x) | Rule: 2x + 1 | Output (y) |
|---|---|---|
| 0 | 2(0) + 1 | 1 |
| 1 | 2(1) + 1 | 3 |
| 2 | 2(2) + 1 | 5 |
| 3 | 2(3) + 1 | 7 |

### 3.6 Linear Functions (ฟังก์ชันเชิงเส้น) — ม.2

$$y = mx + c$$

Where:
- **m** = slope (ความชัน) — rate of change
- **c** = y-intercept (จุดตัดแกน y) — where the line crosses y-axis

## 4 | Common Problem Types

### Type 1: Find the Next Term
> What comes next? 2, 5, 8, 11, ___

Pattern: add 3 each time. Next term = 11 + 3 = **14**.

### Type 2: Find the nth Term
> Find the nth term of: 5, 9, 13, 17...

d = 4. $$a_n = 5 + (n-1) \	imes 4 = 4n + 1$$

### Type 3: Function Machine
> Input → +3 → ×2 → Output. Find output when input = 5.

(5 + 3) × 2 = 8 × 2 = **16**.

### Type 4: Solve for x
> 2x + 7 = 15

2x = 15 − 7 = 8. x = 8 ÷ 2 = **4**.

### Type 5: Pattern in a Table
> Find the rule: (1, 4), (2, 7), (3, 10), (4, 13)

y = 3x + 1 ✓

### Type 6: Quadratic Pattern (ม.3)
> Find the 5th term of: 1, 4, 9, 16...

These are square numbers: 1², 2², 3², 4². 5th term = 5² = **25**.
