# Basic Algebra — พีชคณิตเบื้องต้น

> *"Algebra is the moment mathematics stops being about numbers and starts being about relationships. It is the language in which all of higher mathematics is written."*

Basic Algebra marks the transition from arithmetic (computing with known numbers) to algebra (reasoning about unknown quantities). This topic covers variables, expressions, equations, inequalities, and the properties that govern algebraic manipulation — the essential toolkit for all secondary mathematics and beyond.

| English | Thai | Algebra |

### 3.2 Simplifying Expressions

**Combine like terms:**
$$3x + 5x = 8x$$
$$4a + 2b - a + 3b = 3a + 5b$$

**Distribute:**
$$3(x + 4) = 3x + 12$$
$$-2(3x - 5) = -6x + 10$$

**Expand:**
$$(x + 2)(x + 3) = x^2 + 3x + 2x + 6 = x^2 + 5x + 6$$
$$(x + 4)(x - 4) = x^2 - 16$$

### 3.3 Solving Linear Equations

**Golden rule: Whatever you do to one side, do to the other.**

#### One-step equations:
$$x + 7 = 15 Rightarrow x = 15 - 7 = 8$$
$$3x = 21 Rightarrow x = \rac{21}{3} = 7$$

#### Two-step equations:
$$2x + 5 = 17$$
$$2x = 12$$
$$x = 6$$

#### Equations with variables on both sides:
$$3x + 2 = x + 10$$
$$3x - x = 10 - 2$$
$$2x = 8$$
$$x = 4$$

### 3.4 Solving Inequalities

Same rules as equations, with ONE critical exception:
> **When multiplying or dividing by a negative number, FLIP the inequality sign.**

$$-2x > 8$$
$$x < -4 \quad \	ext{(divide by } -2 \	ext{, flip sign)}$$

**Graphing on number line:**
- `<` or `>` → open circle (○)
- `≤` or `≥` → closed circle (●)

### 3.5 Solving Quadratic Equations (ม.3)

A quadratic equation: $$ax^2 + bx + c = 0$$

#### Method 1: Factoring
$$x^2 - 5x + 6 = 0$$
$$(x - 2)(x - 3) = 0$$
$$x = 2 \	ext{ or } x = 3$$

#### Method 2: Quadratic Formula
$$x = \rac{-b pm \sqrt{b^2 - 4ac}}{2a}$$

#### The Discriminant (b² − 4ac):
| Discriminant | Nature of Roots |
|---|---|
| > 0 | Two distinct real roots |
| = 0 | One real root (double root) |
| < 0 | No real roots (complex) |

## 4 | Common Problem Types

### Type 1: Write an Expression
> Write an expression for "three more than twice a number."

**Answer:** 2x + 3

### Type 2: Simplify
> Simplify: 3(x + 2) − 2(x − 1)

= 3x + 6 − 2x + 2 = **x + 8**

### Type 3: Solve Linear Equation
> Solve: 5x − 3 = 2x + 9

5x − 2x = 9 + 3 → 3x = 12 → **x = 4**

### Type 4: Word Problem → Equation
> A rectangle's length is 3 more than its width. The perimeter is 26. Find the dimensions.

Let w = width. Then l = w + 3. P = 2l + 2w = 26.
2(w + 3) + 2w = 26 → 2w + 6 + 2w = 26 → 4w = 20 → **w = 5, l = 8**.

### Type 5: Quadratic by Factoring
> Solve: x² − 7x + 12 = 0

(x − 3)(x − 4) = 0 → **x = 3 or x = 4**

### Type 6: Inequality
> Solve and graph: 3x − 5 < 10

3x < 15 → x < 5. Graph: open circle at 5, arrow to the left.
