# การเขียนจดหมาย

> เขียนจดหมายส่วนตัวและจดหมายกิจธุระให้ถูกต้องตามรูปแบบ

**การเขียนจดหมาย** คือ การสื่อสารด้วยลายลักษณ์อักษรถึงบุคคลอื่น จดหมายมีหลายประเภท ตั้งแต่จดหมายส่วนตัวที่เขียนถึงเพื่อนหรือครอบครัว ไปจนถึงจดหมายกิจธุระที่เป็นทางการ

---

## เนื้อหาตามช่วงชั้น

| ช่วงชั้น | เนื้อหา |
|---|---|
| **ป.4–6** | เขียนจดหมายส่วนตัวถึงเพื่อนและครอบครัว |
| **ม.1–3** | เขียนจดหมายกิจธุระ จดหมายขอข้อมูล จดหมายร้องเรียน |
| **ม.4–6** | เขียนจดหมายสมัครงาน อีเมลทางการ |

---

## ประเภทของจดหมาย

### 1. จดหมายส่วนตัว (Personal Letter)

**รูปแบบ:**
```
ที่อยู่ผู้ส่ง (มุมขวาบน)
วันที่ (มุมซ้ายบน)

คำขึ้นต้น (เช่น เรียน..., ถึง...)

เนื้อหาจดหมาย

คำลงท้าย (เช่น ด้วยรัก, ด้วยความเคารพ)
ชื่อผู้เขียน
```

**ลักษณะ:**
- ใช้ภาษาพูด กึ่งทางการ
- แสดงความรู้สึกส่วนตัว
- เขียนถึงเพื่อน ครอบครัว คนรู้จัก

### 2. จดหมายกิจธุระ (Business Letter)

**รูปแบบ:**
```
ที่อยู่ผู้ส่ง (มุมขวาบน)
วันที่ (มุมซ้ายบน)

เรื่อง: (ระบุหัวข้อ)
เรียน: (ชื่อผู้รับ)

เนื้อหาจดหมาย

ขอแสดงความนับถือ
ชื่อผู้เขียน
ตำแหน่ง
```

**ลักษณะ:**
- ใช้ภาษาทางการ
- มีจุดประสงค์ชัดเจน
- เขียนถึงบุคคลที่ไม่รู้จักหรือองค์กร

### 3. จดหมายอิเล็กทรอนิกส์ (Email)

**รูปแบบ:**
```
ถึง: (อีเมลผู้รับ)
เรื่อง: (หัวข้ออีเมล)

เนื้อหาอีเมล

คำลงท้าย
ชื่อผู้ส่ง
```

---

## คำขึ้นต้นและคำลงท้าย

| ประเภทจดหมาย | คำขึ้นต้น | คำลงท้าย |
|---|---|---|
| ส่วนตัว | ถึง..., สวัสดี... | ด้วยรัก, รักและคิดถึง |
| กึ่งทางการ | เรียน..., สวัสดีครับ/ค่ะ | ด้วยความเคารพ, ขอแสดงความนับถือ |
| ทางการ | เรียน..., กราบเรียน... | ขอแสดงความนับถือ, ขอแสดงความเคารพอย่างสูง |

---

## เคล็ดลับการเขียนจดหมาย

1. **ระบุจุดประสงค์ชัดเจน**: เขียนเพื่ออะไร (ขอบคุณ ขอโทษ ขอร้อง แจ้งข้อมูล)
2. **ใช้ภาษาเหมาะสม**: ส่วนตัว vs ทางการ
3. **เขียนสั้นกระชับ**: อย่าเขียนเยิ่นเย้อ
4. **ตรวจสอบก่อนส่ง**: ชื่อ ที่อยู่ วันที่ ถูกต้องหรือไม่
5. **ลงท้ายอย่างเหมาะสม**: ใช้คำลงท้ายที่สอดคล้องกับระดับความสนิท
