# การเขียนสะกดคำ

> เขียนคำไทยให้ถูกต้อง: มาตราตัวสะกด คำพ้อง คำที่มักเขียนผิด

**การเขียนสะกดคำ** คือ การเขียนคำภาษาไทยให้ถูกต้องตามหลักเกณฑ์ การสะกดคำที่ถูกต้องเป็นพื้นฐานสำคัญของการสื่อสาร หากเขียนผิดอาจทำให้เข้าใจผิดได้

---

## เนื้อหาตามช่วงชั้น

| ช่วงชั้น | เนื้อหา |
|---|---|
| **ป.1–3** | คำพื้นฐาน คำที่มีตัวสะกดตรงตามมาตรา คำที่มีวรรณยุกต์ |
| **ป.4–6** | คำที่มีตัวสะกดไม่ตรงมาตรา คำพ้อง คำที่มักเขียนผิด |
| **ม.1–3** | คำภาษาต่างประเทศในภาษาไทย คำราชาศัพท์ คำศัพท์วิชาการ |

| มาตรา | ตัวสะกด | ตัวอย่าง |
|---|---|---|
| **แม่กง** | ง | งู, สูง, กลาง |
| **แม่กน** | น, ณ, ร, ล, ฬ | คน, อาหาร, นก |
| **แม่กม** | ม | น้ำ, ลม, บ้าน |
| **แม่เกย** | ย | ชาย, สวย, หอย |
| **แม่เกอว** | ว | ข่าว, เร็ว, เหนียว |
| **แม่กก** | ก, ข, ค | นก, รัก, สุข |
| **แม่กด** | ด, จ, ช, ซ, ฎ, ฏ, ฐ, ฑ, ต, ถ, ท, ธ, ศ, ษ, ส | กด, จัด, ราช |
| **แม่กบ** | บ, ป, พ, ฟ, ภ | กบ, จับ, ภาพ |

| **กาน** | ตัด | กานต้นไม้ |

## เคล็ดลับการจำสะกดคำ

1. **อ่านออกเสียง**: ฟังเสียงแล้วเขียนตาม
2. **แยกพยางค์**: แยกคำเป็นพยางค์แล้วเขียนทีละพยางค์
3. **จำรูปคำ**: จำรูปร่างของคำทั้งคำ
4. **ฝึกเขียนซ้ำๆ**: เขียนคำที่ยากซ้ำหลายครั้ง
5. **ใช้พจนานุกรม**: ค้นหาคำที่ไม่แน่ใจ
