# นิราศเมืองแกลง

> นิราศที่บรรยายความรักและความเสียใจอย่างลึกซึ้ง

---

|---|---|
| **ชื่อผลงาน** | นิราศเมืองแกลง |
| **ผู้แต่ง** | พระสุนทรโวหาร (สุนทรภู่) |
| **ประเภทท** | นิราศ (บทเสภาเล่าการเดินทาง + ความรู้สึก) |
| **เนื้อหา** | บรรยายการเดินทางของสุนทรภู่จากกรุงเทพฯ ไปเมืองแกลง และความเสียใจที่ต้องจากคนรัก |
| **ความสำคัญ** | นิราศที่แสดงอารมณ์ความรักและความเสียใจอย่างลึกซึ้ง |
| **ฉันทลักษณ์** | กลอนแปด (กลอนสุภาพ) |

## วรรณศิลป์

| วิธีการ | รายละเอียด |
|---|---|
| **กลอนสุภาพ** | ใช้กลอนแปด (กลอนสุภาพ) |
| **โวหารพรรณnา** | บรรยายธรรมชาติริมทางและความรู้สึก |
| **โวหารเทศนา** | แสดงความรู้สึก ความคิด ขณะเดินทาง |
| **ภาพพจน์** | เปรียบเทียบธรรมชาติกับความรู้สึก |

---

## คติธรรมและคุณค่า

| ประเภทท | รายละเอียด |
|---|---|
| **คุณค่าทางวรรณศิลป์** | แบบอย่างของนิราศที่บรรยายอารมณ์อย่างลึกซึ้ง |
| **คุณค่าทางภาษา** | ภาษาสุนทรภู่ที่เรียบง่ายแต่ไพเราะ |
| **ข้อคิด** | ความรักทำให้ผู้คนมีความหวังและความเสียใจ |

---

## สรุปสำคัญ

1. **นิราศเมืองแกลง** เป็นนิราศที่บรรยายการเดินทางของสุนทรภู่
2. **แก่นเรื่อง** ความรัก ความเสียใจ โหยหา
3. **กลอนสุภาพ** ที่ไพเราะ บรรยายธรรมชาติและอารมณ์
4. **กวีแห่งประชาชน** ภาษาเรียบง่าย แต่สะท้อนอารมณ์อย่างลึกซึ้ง
