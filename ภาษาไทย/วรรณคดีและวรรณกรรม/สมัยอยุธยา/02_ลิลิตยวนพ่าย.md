# ลิลิตยวนพ่าย

> วรรณคดีอุทิศแด่ชัยชนะเหนือข้าศึก

---

## เกี่ยวกับผลงาน

| รายละเอียด | ข้อมูล |
|---|---|
| **ชื่อผลงาน** | ลิลิตยวนพ่าย |
| **ผู้แต่ง** | ไม่ปรากฏ |
| **ช่วงเวลา** | สมัยอยุธยาตอนต้น (สมเด็จพระบรมราชาธิราชที่ ๒) |
| **ประเภทท** | ลิลิต (ผสมร้อยแก้ว ร้อยกรอง หลายชนิด) |
| **เนื้อหา** | บรรยายการศึกสมเด็จพระบรมราชาธิราชที่ ๒ ตีเมืองเชียงใหม่ (ยวน/ล้านนา) |
| **ความสำคัญ** | วรรณคดีประวัติศาสตร์ที่บรรยายสงครามอย่างสมจริง |
| **ฉันทลักษณ์** | ลิลิต: ผสมร่าย โคลง คำฉันท์ กาพย์ |

---

## เนื้อหาสาระ

ลิลิตยวนพ่ายบรรยายการศึกที่สมเด็จพระบรมราชาธิราชที่ ๒ (เจ้าสามพระยก) ยกทัพไปตีเมืองเชียงใหม่ แต่ไม่สามารถตีได้

```mermaid
flowchart LR
    A["เตรียมทัพ"] --> B["ยกทัพไปเชียงใหม่"]
    B --> C["รบพุ่งกับทัพยวน"]
    C --> D["ล้อมเมือง"]
    D --> E["ยวนต้านทาน
ทัพไทยลำบาก"]
    E --> F["สงบศึก กลับอยุธยา"]
```

---

## บทอักษรสำคัญ + คำแปลปัจจุบัน

### ตอนที่ ๑: การยกทัพ

> **ภาษาเดิม:**
> พระบาทสมเด็จพระเป็นเจ้า ทรงพระกรุณาโปรดให้ยกพยุหโยธา ออกไปหนองโสนแต่เช้าตรู่...

> **คำแปลปัจจุบัน:**
> พระบาทสมเด็จพระเจ้าอยู่หัว โปรดให้ยกกองทัพออกไปหนองโสนแต่เช้าตรู่...

### ตอนที่ ๒: การรบ

> **ภาษาเดิม:**
> พวกข้าศึกเห็นกองทัพไทย ก็มิได้ขวัญและกล้าหาญ จึงต่อสู้อย่างอาวุธสาป...

> **คำแปลปัจจุบัน:**
> พวกข้าศึกเห็นกองทัพไทย ก็ทำให้ขวัญและกล้าหาญ จึงต่อสู้อย่างอาวุธสาป...

## วรรณศิลป์

| วิธีการ | รายละเอียด |
|---|---|
| **การบรรยายสมจริง** | บรรยายการรบอย่างสมจริง สะท้อนประวัติศาสตร์ |
| **รูปแบบลิลิต** | ผสมหลายฉันทลักษณ์ (ร่าย โคลง คำฉันท์ กาพย์) |
| **โวหารเทศนา** | สรรเสริญพระมหากรุณาธิบดี |
| **ภาษาอนุรักษ์** | ใช้คำโบราณและราชาศัพท์ |

---

## คติธรรมและคุณค่า

| ประเภทท | รายละเอียด |
|---|---|
| **คุณค่าทางประวัติศาสตร์** | บันทึกการศึกอยุธยา-เชียงใหม่ |
| **คุณค่าทางวรรณศิลป์** | ลิลิตที่สมบูรณ์ที่สุดเรื่องหนึ่ง |
| **คุณค่าทางสังคม** | สะท้อนสภาพสังคมสงคราม |
| **ข้อคิด** | สงครามเป็นเรื่องยาก ชัยชนะไม่ได้มาง่าย |

---

## คำศัพท์เฉพาะ

| คำโบราณ | คำปัจจุบัน | หมายเหตุ |
|---|---|---|
| ยวน | ล้านนา / คนเชียงใหม่ | คำเรียกคนล้านนา |
| พยุหโยธา | กองทัพ | คำราชาศัพท์ |
| ข้าศึก | ศัตรู | คำสันสกฤต |
| ขวัญและกล้าหาญ | ขวัญและความกล้า | คำคู่ |
| หนองโสน | ชื่อสถานที่ | บริเวณทุ่งศรีอยุธยา |
| อาวุธสาป | อาวุธปืน/ปืนใหญ่ | ปืนโบราณ |

## สรุปสำคัญ

1. **ลิลิตยวนพ่าย** บรรยายการศึกอยุธยา-เชียงใหม่ (ล้านนา)
2. **รูปแบบลิลิต** ผสมหลายฉันทลักษณ์: ร่าย โคลง คำฉันท์ กาพย์
3. **คุณค่าทางประวัติศาสตร์** บันทึกสงครามและสภาพสังคมสมัยอยุธยา
4. **สงครามเป็นเรื่องยาก** ชัยชนะไม่ได้มาง่าย ต้องอาศัยความอดทน
