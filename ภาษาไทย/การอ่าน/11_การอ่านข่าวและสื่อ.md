# การอ่านข่าวและสื่อ

> อ่านข่าวอย่างมีวิจารณญาณ: เข้ารู้เท่าทันสื่อ รู้จักข่าวปลอม

ในยุคดิจิทัล การอ่านข่าวและสื่อออนไลน์เป็นทักษะที่จำเป็น ผู้เรียนต้องสามารถ **แยกข่าวจริงจากข่าวปลอม** เข้าใจเทคนิคการเขียนข่าว และรู้เท่าทันอิทธิพลของสื่อ

---

## เนื้อหาตามช่วงชั้น

| ช่วงชั้น | เนื้อหา |
|---|---|
| **ป.4–6** | อ่านข่าวกิจกรรมโรงเรียน ข่าวสำหรับเด็ก |
| **ม.1–3** | อ่านข่าวประจำวัน บทความออนไลน์ วิเคราะห์ข่าวเบื้องต้น |
| **ม.4–6** | รู้เท่าทันสื่อ วิเคราะห์อคติของสื่อ ข่าวปลอม (Fake News) สื่อสังคมออนไลน์ |

---

## โครงสร้างข่าว

| ส่วน | เนื้อหา |
|---|---|
| **พาดหัว** | หัวข้อข่าว ดึงดูดความสนใจ |
| **โปรย** | สรุปย่อประเด็นสำคัญ |
| **ย่อหน้าแรก** | ข้อมูลสำคัญที่สุด (ใคร ทำอะไร ที่ไหน เมื่อไร) |
| **เนื้อเรื่อง** | รายละเอียดเพิ่มเติม ตามลำดับความสำคัญ |
| **พื้นหลัง** | ข้อมูลที่เกี่ยวข้อง บริบท |

---

## วิธีแยกข่าวปลอม (Fake News)

| สัญญาณ | รายละเอียด |
|---|---|
| พาดหัวเกินจริง | ใช้คำที่ทำให้ตกใจหรือโกรธ |
| ไม่มีแหล่งที่มา | ไม่ระบุชื่อผู้เขียนหรือแหล่งข้อมูล |
| วันที่เก่า | นำข่าวเก่ามาแชร์ใหม่เหมือนเพิ่งเกิด |
| ภาพตัดต่อ | ภาพไม่ตรงกับเนื้อหา หรือถูกตัดต่อ |
| อคติชัดเจน | เขียนเข้าข้างฝ่ายใดฝ่ายหนึ่งอย่างชัดเจน |

---

## เคล็ดลับ

1. **เช็คแหล่งที่มา**: สื่อหลักที่น่าเชื่อถือ หรือบล็อกที่ไม่รู้จัก?
2. **เช็ควันที่**: ข่าวใหม่หรือข่าวเก่า?
3. **เช็คกับแหล่งอื่น**: สื่ออื่นรายงานเหมือนกันหรือไม่?
4. **ระวังอารมณ์**: ถ้าอ่านแล้วโกรธหรือกลัวมาก ให้หยุดคิดก่อนเชื่อ
