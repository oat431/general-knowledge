# การอ่านออกเสียงร้อยกรอง (ทำนองเสนาะ)

> อ่านบทร้อยกรองด้วยจังหวะ สัมผัส และทำนองที่ถูกต้อง

**ร้อยกรอง** คือ ข้อความที่มีรูปแบบสัมผัสและจำนวนคำตามฉันทลักษณ์ ได้แก่ กลอน โคลง ฉันท์ กาพย์ ร่าย การอ่านร้อยกรองเรียกว่า **การอ่านทำนองเสนาะ** ซึ่งต้องเข้าใจโครงสร้างของร้อยกรองแต่ละประเภท

---

## เนื้อหาตามช่วงชั้น

| ช่วงชั้น | เนื้อหา |
|---|---|
| **ป.4–6** | อ่านกลอนสี่ กลอนหก ด้วยจังหวะพื้นฐาน |
| **ม.1–3** | อ่านกลอนสุภาพ (กลอนแปด) โคลงสี่สุภาพ กาพย์ยานี 11 ด้วยทำนองเสนาะ |
| **ม.4–6** | อ่านบทร้อยกรองทุกรูปแบบ: กลอน โคลง ฉันท์ กาพย์ ร่าย ด้วยความเชี่ยวชาญ |

---

## การอ่านร้อยกรองแต่ละประเภท

### กลอน (กลอนสุภาพ — กลอนแปด)

```
หนึ่งวรรคมี 7–9 คำ          แบ่ง 2 จังหวะ
วรรคสดับ → วรรครับ →        วรรครอง → วรรคส่ง

ตัวอย่าง:
มานี / มี // หนังสือ / ใหม่     ← วรรคสดับ + วรรครับ
มานี / ชอบ // อ่าน / ทุกวัน      ← วรรครอง + วรรคส่ง
```

| วรรค | จำนวนคำ | จุดสัมผัส |
|---|---|---|
| สดับ | 5–9 คำ | สัมผัสกับวรรครับคำสุดท้าย |
| รับ | 5–9 คำ | สัมผัสกับวรรครองคำที่ 3–5 |
| รอง | 5–9 คำ | สัมผัสกับวรรคส่งคำสุดท้าย |
| ส่ง | 5–9 คำ | สัมผัสกับบทถัดไป |

### โคลงสี่สุภาพ

- 4 วรรค / บาท: บาทเอก (วรรค 1–2) + บาทโท (วรรค 3–4)
- มี **คำเอก** (รูปไม้เอก) และ **คำโท** (รูปไม้โท) ตามตำแหน่งบังคับ
- อ่านช้ากว่ากลอน เน้นความหนักแน่นของเสียง

### ฉันท์

- ใช้หลัก **ครุ–ลหุ** (หนัก–เบา) แทนจำนวนคำ
- **ครุ** (─): สระยาว หรือคำที่มีตัวสะกด
- **ลหุ** (∪): สระสั้นที่ไม่มีตัวสะกด
- อ่านด้วยจังหวะตามรูปแบบครุ–ลหุ

### กาพย์

| ประเภท | จำนวนคำ/บาท | ลักษณะ |
|---|---|---|
| กาพย์ยานี 11 | 11 คำ (5+6) | อ่านเร็ว กระชับ |
| กาพย์ฉบัง 16 | 16 คำ (6+4+6) | อ่านจังหวะปานกลาง |
| กาพย์สุรางคนางค์ 28 | 28 คำ (4×7) | อ่านเป็นท่อนๆ |

### ร่าย

- คำสุดท้ายวรรคนี้ → สัมผัสกับคำแรกของวรรคถัดไป (สัมผัสระหว่างวรรค)
- อ่านต่อเนื่องเหมือนการพูดเป็นทำนอง
- ประเภท: ร่ายโบราณ, ร่ายสุภาพ, ร่ายดั้น, ร่ายยาว

---

## เคล็ดลับการอ่านทำนองเสนาะ

1. อ่านเนื้อเรื่องให้เข้าใจความหมายก่อน
2. แบ่งวรรคให้ถูกต้องตามฉันทลักษณ์
3. ฝึกอ่านช้าๆ ก่อน แล้วค่อยเพิ่มความเร็ว
4. ใส่เสียงสูง-ต่ำตามความหมายของคำ
