# การอ่านออกเสียงขั้นพื้นฐาน

> ทักษะแรกของการอ่าน: ออกเสียงคำให้ถูกต้องตามหลักภาษาไทย

การอ่านออกเสียงขั้นพื้นฐานเป็นรากฐานของการเรียนรู้ภาษาไทย เริ่มตั้งแต่การจดจำพยัญชนะ สระ วรรณยุกต์ และการประสมคำ ผู้เรียนต้องเข้าใจ **อักษรสามหมู่** (อักษรสูง อักษรกลาง อักษรต่ำ) และ **มาตราตัวสะกด** เพื่อออกเสียงคำได้ถูกต้อง

---

## เนื้อหาตามช่วงชั้น

| ช่วงชั้น | เนื้อหา |
|---|---|
| **ป.1** | จำพยัญชนะ 44 รูป สระ 32 รูป เสียงวรรณยุกต์ 5 เสียง อ่านคำประสมสระเสียงสั้น-ยาว |
| **ป.2** | อ่านคำที่มีตัวสะกดตรงตามมาตรา (แม่กง กน กม เกย เกอว) อ่านคำที่มีรูปวรรณยุกต์ |
| **ป.3** | อ่านคำที่มีตัวสะกดไม่ตรงมาตรา อ่านคำควบกล้ำ (กว้าง, ปลา, กราบ) อ่านคำที่มีอักษรนำ (หญิง, ใหญ่) อ่านคำที่มีตัวการันต์ |
| **ป.4–6** | อ่านออกเสียงร้อยแก้วและร้อยกรองด้วยจังหวะและน้ำเสียงที่เหมาะสม |
| **ม.1–3** | อ่านทำนองเสนาะ อ่านบทละครด้วยอารมณ์ |
| **ม.4–6** | อ่านบทร้อยกรองทุกรูปแบบ (กลอน โคลง ฉันท์ กาพย์ ร่าย) ด้วยความเชี่ยวชาญ |

## หลักการอ่านออกเสียง

### 1. การผันวรรณยุกต์

วรรณยุกต์ของคำขึ้นอยู่กับ 3 ปัจจัย:

| ปัจจัย | รายละเอียด |
|---|---|
| **อักษรหมู่** | สูง (ข ฉ ถ ผ ฝ ศ ษ ส ห) / กลาง (ก จ ด ต บ ป อ) / ต่ำ (ค ง ช ท น พ ม ย ร ล ว) |
| **รูปวรรณยุกต์** | ่ (เอก) ้ (โท) ๊ (ตรี) ๋ (จัตวา) หรือไม่มีรูป |
| **ชนิดพยางค์** | คำเป็น (สระยาว/ตัวสะกดแม่กง กน กม เกย เกอว) / คำตาย (สระสั้น/ตัวสะกดแม่กก กด กบ) |

### 2. มาตราตัวสะกด 8 มาตรา

| มาตรา | เสียง | ตัวสะกด |
|---|---|---|
| แม่ก กา | ไม่มีตัวสะกด | — |
| แม่กง | ง | ง |
| แม่กน | น | น ณ ร ล ฬ |
| แม่กม | ม | ม |
| แม่เกย | ย | ย |
| แม่เกอว | ว | ว |
| แม่กก | ก | ก ข ค ฆ |
| แม่กด | ด | ด จ ช ซ ฌ ฎ ฏ ฐ ฑ ฒ ต ถ ท ธ ศ ษ ส |
| แม่กบ | บ | บ ป ผ ฝ พ ฟ ภ |

### 3. คำควบกล้ำ

- **ควบแท้**: ออกเสียงพยัญชนะทั้งสองพร้อมกัน → กวาง, ขวาน, ปลา, กราบ
- **ควบไม่แท้**: ออกเสียงเฉพาะพยัญชนะตัวแรก → จริง (จิง), ทราบ (ซาบ), ศรี (สี)

---

## ตัวอย่างการฝึกอ่าน

**ป.1–2**: "แม่ไปตลาด ซื้อผักสด ปลาสด"

**ป.3**: "ขวัญชอบเล่นกว้าง ๆ ในสวนหลังบ้าน"

**ป.4–6**: "พระอาทิตย์ตกดิน ท้องฟ้าเปลี่ยนเป็นสีส้ม แดง ม่วง อย่างสวยงาม"

---

## เคล็ดลับ

- ฝึกผันวรรณยุกต์ทุกวัน: ก่า ก้า ก๊า ก๋า
- แยกคำเป็น/คำตาย ให้ได้ก่อนเรียนผันวรรณยุกต์
- คำควบกล้ำไม่แท้ต้องจำ ไม่ใช่ผันตามรูป
