# การอ่านแผนที่ แผนภูมิ และกราฟ

> อ่านและตีความข้อมูลจากสื่อที่ไม่ใช่ข้อความ

การอ่าน **แผนที่ แผนภูมิ และกราฟ** เป็นทักษะการอ่านข้อมูลจากภาพและสัญลักษณ์ ผู้เรียนต้องเข้าใจความหมายของสัญลักษณ์ แกนข้อมูล มาตราส่วน และประเภทของแผนภูมิ เพื่อตีความข้อมูลได้อย่างถูกต้อง

---

## เนื้อหาตามช่วงชั้น

| ช่วงชั้น | เนื้อหา |
|---|---|
| **ป.4–6** | อ่านแผนที่ง่ายๆ อ่านแผนภูมิแท่ง แผนภูมิวงกลม |
| **ม.1–3** | อ่านกราฟเส้น กราฟแท่งหลายชุด ตารางสถิติ |
| **ม.4–6** | อ่านแผนภูมิที่ซับซ้อน อินโฟกราฟิก ข้อมูลทางสถิติ |

---

## ประเภทของสื่อข้อมูล

### แผนที่

| องค์ประกอบ | ความหมาย |
|---|---|
| สัญลักษณ์ | รูปภาพแทนสิ่งต่างๆ (โรงเรียน โรงพยาบาล แม่น้ำ) |
| มาตราส่วน | อัตราส่วนระยะทางในแผนที่ต่อระยะทางจริง |
| เข็มทิศ | ทิศเหนือ-ใต้-ตะวันออก-ตก |
| คำอธิบายสัญลักษณ์ | ความหมายของแต่ละสัญลักษณ์ |

### แผนภูมิ

| ประเภท | ใช้สำหรับ |
|---|---|
| **แผนภูมิแท่ง** | เปรียบเทียบปริมาณ |
| **แผนภูมิวงกลม** | แสดงสัดส่วน/ร้อยละ |
| **แผนภูมิเส้น** | แสดงแนวโน้มตามเวลา |
| **แผนภูมิแท่งซ้อน** | เปรียบเทียบหลายชุดข้อมูล |
| **ฮิสโทแกรม** | แสดงการกระจายของข้อมูล |

### กราฟและตาราง

- **ตาราง**: ข้อมูลเป็นแถวและหลัก อ่านโดยการหาจุดตัด
- **กราฟผสม**: มีทั้งกราฟเส้นและแท่งในแผนภาพเดียว ต้องอ่านคำอธิบายแกนทั้งสอง

---

## ขั้นตอนการอ่านสื่อข้อมูล

1. อ่าน **ชื่อเรื่อง** → รู้ว่าข้อมูลเกี่ยวกับอะไร
2. อ่าน **คำอธิบายแกน/สัญลักษณ์** → เข้าใจหน่วยและที่มา
3. อ่าน **ข้อมูล** → สังเกตค่าสูงสุด ต่ำสุด แนวโน้ม
4. **ตีความ** → สรุปว่าข้อมูลบอกอะไร
