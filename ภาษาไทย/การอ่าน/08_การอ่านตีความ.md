# การอ่านตีความ

> เข้าใจความหมายที่ซ่อนอยู่: อ่านระหว่างบรรทัด เข้าใจเจตนาของผู้เขียน

**การอ่านตีความ** คือ การทำความเข้าใจความหมายที่ผู้เขียนไม่ได้เขียนไว้โดยตรง แต่ซ่อนอยู่ในบริบท น้ำเสียง หรือภาษา figurative เป็นการ "อ่านระหว่างบรรทัด" เพื่อเข้าใจสิ่งที่ผู้เขียนต้องการสื่อจริงๆ

---

## เนื้อหาตามช่วงชั้น

| ช่วงชั้น | เนื้อหา |
|---|---|
| **ป.4–6** | เข้าใจความหมายโดยนัยจากบริบทและภาพประกอบ เข้าใจสำนวนไทย |
| **ม.1–3** | ตีความสัญลักษณ์ แก่นเรื่อง สารจากผู้เขียน ในวรรณกรรม |
| **ม.4–6** | ตีความวรรณกรรมที่ซับซ้อน เข้าใจอุปมานิทัศน์ (allegory) และความหมายหลายชั้น |

## เทคนิคการตีความ

### 1. ใช้บริบท (context clues)

| เทคนิค | ตัวอย่าง |
|---|---|
| คำจำกัดความในประโยค | "สัตว์เลี้ยงลูกด้วยนม คือ สัตว์ที่เลี้ยงลูกด้วยน้ำนม" |
| คำตรงข้าม | "เขาขยัน ตรงข้ามกับเพื่อนที่เกียจคร้าน" |
| ตัวอย่าง | "ผลไม้เมืองร้อน เช่น ทุเรียน มังคุด ลำไย" |
| ภาพรวม | อ่านทั้งย่อหน้าแล้วอนุมานความหมาย |

### 2. เข้าใจสำนวนไทย

| สำนวน | ความหมาย |
|---|---|
| น้ำขึ้นให้รีบตัก | มีโอกาสต้องรีบคว้า |
| เข้าเมืองตาหลิ่วต้องหลิ่วตาตาม | เข้าที่ใดต้องทำตามธรรมเนียมที่นั่น |
| ช้าๆ ได้พร้าสองเล่มงาม | ทำอย่างรอบคอบย่อมได้ผลดี |
| ใกล้เกลือกินด่าง | มีสิ่งดีอยู่ใกล้ตัวแต่ไม่รู้จักใช้ |

### 3. ตีความสัญลักษณ์

- สี → อารมณ์ (สีแดง = ความโกรธ, สีขาว = ความบริสุทธิ์)
- สภาพอากาศ → บรรยากาศ (ฝนตก = ความเศร้า, แดดออก = ความสุข)
- สัตว์ → บุคลิก (สุนัขจิ้งจอก = ความเจ้าเล่ห์, นกอินทรี = อำนาจ)
