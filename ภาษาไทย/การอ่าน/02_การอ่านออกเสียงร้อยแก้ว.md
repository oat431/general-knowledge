# การอ่านออกเสียงร้อยแก้ว

> อ่านบทความ ข่าว ประกาศ ด้วยน้ำเสียงและจังหวะที่ถูกต้อง

**ร้อยแก้ว** คือ ข้อความที่ไม่ใช่บทร้อยกรอง ได้แก่ บทความ ข่าว ประกาศ นิทาน สารคดี การอ่านออกเสียงร้อยแก้วต้องเน้น **การเว้นจังหวะ** **การเน้นคำสำคัญ** และ **น้ำเสียงที่เหมาะสม** กับประเภทของข้อความ

---

## เนื้อหาตามช่วงชั้น

| ช่วงชั้น | เนื้อหา |
|---|---|
| **ป.4–6** | อ่านออกเสียงบทความ ข่าวสั้น นิทาน ด้วยน้ำเสียงปกติ เว้นจังหวะตามเครื่องหมายวรรคตอน |
| **ม.1–3** | อ่านออกเสียงสารคดี บทความวิชาการ ปรับน้ำเสียงตามเนื้อหา |
| **ม.4–6** | อ่านออกเสียงงานเขียนเชิงวรรณศิลป์ ด้วยความเข้าใจในลีลาการประพันธ์ |

---

## หลักการอ่านร้อยแก้ว

### 1. การเว้นจังหวะ

| เครื่องหมาย | การเว้นจังหวะ |
|---|---|
| จุลภาค (,) | เว้นสั้น |
| อัฒภาค (;) | เว้นปานกลาง |
| มหัพภาค (.) | เว้นยาว |
| ยัติภังค์ (-) | ไม่เว้น |
| ไปยานน้อย (ฯ) | เว้นสั้น |

### 2. การเน้นเสียง

- **คำสำคัญ** (คำนาม กริยาหลัก): เน้นเสียงให้ชัดเจน
- **คำเชื่อม** (และ แต่ หรือ): อ่านเบากว่า
- **คำขยาย** (คำวิเศษณ์): ปรับน้ำเสียงตามความหมาย

### 3. น้ำเสียงตามประเภทข้อความ

| ประเภท | น้ำเสียง |
|---|---|
| ข่าว | เป็นทางการ ชัดเจน |
| นิทาน | มีชีวิตชีวา เปลี่ยนเสียงตามตัวละคร |
| สารคดี | กระตือรือร้น น่าสนใจ |
| ประกาศ | ดัง ชัดเจน มั่นใจ |

## ตัวอย่าง

**ข่าว**: "สำนักข่าว // รายงานว่า // น้ำท่วมในภาคกลาง // ส่งผลกระทบต่อประชาชน // กว่าหนึ่งหมื่นครัวเรือน"

> เครื่องหมาย // แสดงจุดเว้นจังหวะ
