# การอ่านวรรณคดีและวรรณกรรม

> อ่านวรรณคดีเพื่อความซาบซึ้ง: เข้าใจคุณค่าทางวรรณศิลป์

การอ่านวรรณคดีและวรรณกรรมแตกต่างจากการอ่านสารคดี เพราะต้องอ่านเพื่อ **ซาบซึ้ง** ในความงามของภาษา เข้าใจ **คุณค่าทางวรรณศิลป์** และวิเคราะห์แก่นเรื่อง ตัวละคร และบริบททางสังคม

---

## เนื้อหาตามช่วงชั้น

| ช่วงชั้น | เนื้อหา |
|---|---|
| **ป.1–3** | อ่านนิทาน บทร้อยกรองง่ายๆ |
| **ป.4–6** | อ่านวรรณคดีลำนำ (ตอนสั้นๆ จากวรรณคดีเอก) |
| **ม.1–3** | อ่านวรรณคดีเอก วิเคราะห์ตัวละคร แก่นเรื่อง |
| **ม.4–6** | วิเคราะห์วรรณคดีเชิงลึก เปรียบเทียบวรรณคดีต่างยุค |

---

## องค์ประกอบของวรรณกรรม

| องค์ประกอบ | รายละเอียด |
|---|---|
| **โครงเรื่อง** | ลำดับเหตุการณ์ (เปิดเรื่อง → พัฒนา → จุดสูงสุด → คลี่คลาย → จบ) |
| **ตัวละคร** | ตัวเอก ตัวรอง ตัวประกอบ / ตัวละครแบน-ตัวละครกลม |
| **ฉาก** | สถานที่ เวลา บรรยากาศ |
| **แก่นเรื่อง** | ข้อคิดหรือสาระสำคัญที่ผู้เขียนต้องการสื่อ |
| **มุมมองการเล่าเรื่อง** | บุรุษที่ 1 (ฉัน) / บุรุษที่ 3 (เขา) |
| **ลีลาภาษา** | การใช้โวหาร สำนวน เสียงสัมผัส |

---

## คุณค่าของวรรณคดี

| คุณค่า | รายละเอียด |
|---|---|
| **คุณค่าทางวรรณศิลป์** | ความงามของภาษา กลวิธีทางวรรณศิลป์ |
| **คุณค่าทางสังคม** | สะท้อนสังคม วัฒนธรรม ยุคสมัย |
| **คุณค่าทางจริยธรรม** | ให้ข้อคิด สอนคุณธรรม |
| **คุณค่าทางปัญญา** | กระตุ้นความคิด เปิดโลกทัศน์ |
