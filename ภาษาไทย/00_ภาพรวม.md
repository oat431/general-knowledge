# ภาษาไทย: ภาพรวม

> ภาษาไทยเป็นสมบัติล้ำค่าของชาติ เป็นเครื่องมือสื่อสาร และเป็นคลังปัญญาที่สืบทอดกันมาแต่โบราณกาล

**ภาษาไทย** เป็นวิชาบังคับสำหรับนักเรียนไทยทุกคน ตั้งแต่ ป.1 ถึง ม.6 รวม 12 ปีการศึกษา ครอบคลุมทักษะทางภาษาทุกด้าน ตั้งแต่การอ่านออกเสียงเบื้องต้นไปจนถึงการวิเคราะห์วรรณคดีขั้นสูง

---

อ่านจากฐานขึ้นไป: หลักการใช้ภาษาไทยเป็นฐานของอีกสี่สาระ และสี่ทักษะรวมกันเป็นทางเข้าสู่วรรณคดี สีบอกกลุ่มของสาระ คือ ฐานราก (เขียวหม่น) ทักษะการรับสาร (เทอร์ควอยซ์) ทักษะการส่งสาร (เขียว) และการประยุกต์ใช้ (เขียวมรกต)

## สาระการเรียนรู้ทั้ง 5

| สาระ | ชื่อ | จำนวนหัวข้อ | ทักษะหลัก |
|---|---|---|---|
| **สาระที่ 1** | [[ภาษาไทย/การอ่าน/00_ภาพรวมการอ่าน\|การอ่าน]] | ~15 | อ่านออกเสียง → จับใจความ → วิเคราะห์ → วิจารณ์ |
| **สาระที่ 2** | [[ภาษาไทย/การเขียน/00_ภาพรวมการเขียน\|การเขียน]] | ~15 | คัดลายมือ → แต่งประโยค → เรียงความ → เขียนวิชาการ |
| **สาระที่ 3** | [[ภาษาไทย/การฟัง การดู และการพูด/00_ภาพรวมการฟัง การดู และการพูด\|การฟัง การดู และการพูด]] | ~10 | ฟังจับใจความ → วิเคราะห์สื่อ → พูดแสดงความคิดเห็น → สุนทรพจน์ |
| **สาระที่ 4** | [[ภาษาไทย/หลักการใช้ภาษาไทย/00_ภาพรวมหลักการใช้ภาษาไทย\|หลักการใช้ภาษาไทย]] | ~23 | สะกดคำ → ชนิดคำ → ประโยค → ระดับภาษา → ฉันทลักษณ์ |
| **สาระที่ 5** | [[ภาษาไทย/วรรณคดีและวรรณกรรม/00_ภาพรวม\|วรรณคดีและวรรณกรรม]] | ~15 | นิทาน → วรรณคดีมรดก → วรรณกรรมปัจจุบัน → วรรณคดีวิจักษณ์ |

## การแบ่งช่วงชั้น

| ช่วงชั้น | ระดับ | ลักษณะการเรียนรู้ |
|---|---|---|
| **ช่วงชั้นที่ 1** | ป.1–3 | สร้างพื้นฐาน: อ่านออกเขียนได้ สะกดคำ เรียนพยัญชนะ สระ วรรณยุกต์ |
| **ช่วงชั้นที่ 2** | ป.4–6 | พัฒนาทักษะ: จับใจความ วิเคราะห์เบื้องต้น เขียนเรียงความ ย่อความ |
| **ช่วงชั้นที่ 3** | ม.1–3 | เชิงวิเคราะห์: วิเคราะห์ ตีความ วิจารณ์ อ่านวรรณคดี แต่งบทร้อยกรอง |
| **ช่วงชั้นที่ 4** | ม.4–6 | เชิงวิชาการ: วิพากษ์ เขียนเชิงวิชาการ วิเคราะห์วรรณคดี ฉันทลักษณ์ขั้นสูง |
