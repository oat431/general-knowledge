# Computer Science — Book Checklist

> **Subject:** Computer Science (วิทยาการคำนวณ) — ม.4–ม.6 (ว331–ว333)
> **Related Overview:** [[05_Computer Science - Overview]]

## 🔴 Essential

### IPST Textbooks (สสวท.)
| Book | Publisher | Notes |
|---|---|---|
| วิทยาการคำนวณ ม.4 | สสวท. | Computational Thinking, Data Representation, Boolean Logic, Programming — [Free PDF](https://www.ipst.ac.th) |
| วิทยาการคำนวณ ม.5 | สสวท. | Functions, Algorithms, Data Structures, OOP |
| วิทยาการคำนวณ ม.6 | สสวท. | Computer Systems, Networks, Databases, AI |

### Programming
| Book | Author/Publisher | Notes |
|---|---|---|
| Python Crash Course | Eric Matthes | Best beginner Python book — clear, project-based |
| Automate the Boring Stuff with Python | Al Sweigart | Practical Python — free online at [automatetheboringstuff.com](https://automatetheboringstuff.com) |

## 🟡 Recommended

### Thai Study Books
| Book | Author/Publisher | Notes |
|---|---|---|
| ตะลุยโจทย์ วิทยาการคำนวณ | Various | Practice problems for the CS exam |
| A-Level ตะลุยโจทย์ วิทยาการคำนวณ | Various | Newest exam format (2024+) |

### International Textbooks
| Book | Author | Notes |
|---|---|---|
| Computer Science: An Overview | Glenn Brookshear | Broad CS overview — good for understanding the big picture |
| Introduction to Algorithms (CLRS) | Cormen et al. | For deeper algorithm study (university level) |

## 🟢 Optional

| Book | Author | Notes |
|---|---|---|
| Code: The Hidden Language of Computer Hardware and Software | Charles Petzold | For understanding how computers actually work |
| Think Python | Allen Downey | Free online — good for learning Python with CS concepts |
| SQL in 10 Minutes | Ben Forta | For database fundamentals |

## Exam Relevance

| Exam | CS Topics | Key Books |
|---|---|---|
| **O-NET** | Basic CS concepts | IPST textbooks |
| **A-Level** | Full ม.4-ม.6 scope | A-Level ตะลุยโจทย์ |
| **PAT1** | Some logic/algorithm questions | Programming practice |

## Note

> Computer Science is a newer subject in the Thai curriculum (added in 2017 revision). Fewer dedicated exam prep books exist compared to Math/Physics/Chemistry/Biology. IPST textbooks are the primary reference.
