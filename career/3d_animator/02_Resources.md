## 📖 Books

Animation books age beautifully (principles never change); software books do not (Blender updates too fast). So: buy animation books, learn software from YouTube.

| Book | Author | Why |
|---|---|---|
| **The Animator's Survival Kit** ⭐ | Richard Williams | THE animation textbook: walks, weight, timing. Used for a decade |
| Cartoon Animation | Preston Blair | Cheap (~400 THB) classic for principles + drawing |
| The Animator's Workbook | Tony White | Exercise-based; pairs with Phase 3 |
| The Illusion of Life | Frank Thomas & Ollie Johnston | The Disney founders on the 12 Principles — a "later" book |
| Drawn to Life (2 vols) | Walt Stanchfield | Gesture drawing and acting for animators |
| Learning Blender (3rd ed.) | Oliver Villar | Only Blender book worth considering — still optional vs YouTube |

## How to use this file

1. **Spine first, always.** The spine table is the curriculum; channels and courses are satellites around it.
2. **One tutorial at a time.** Finish one project before starting the next.
3. **Version rule:** a tutorial made for Blender 3.x/4.x still teaches 95% of the skill in 5.x. If a button moved, press `F3` and search its name.
