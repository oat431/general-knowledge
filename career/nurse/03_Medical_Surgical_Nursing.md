# 03 — Medical-Surgical Nursing

> *"The med-surg nurse is the generalist who knows a little about everything and a lot about the patient."*

Medical-Surgical Nursing (การพยาบาลอายุรศาสตร์และศัลยศาสตร์) is the largest clinical domain. It covers the nursing care of **adult patients** with medical conditions or undergoing surgery. This is the backbone of hospital nursing, taught across **Year 2–3**.

---

## 1 | Body Systems & Common Conditions

### 1.1 Cardiovascular (ระบบหัวใจและหลอดเลือด)

| Condition | Key Nursing Care |
|---|---|
| **Hypertension (ความดันโลหิตสูง)** | BP monitoring, medication adherence, DASH diet, Na⁺ restriction |
| **Heart Failure (ภาวะหัวใจล้มเหลว)** | Daily weight, I/O monitoring, fluid restriction, O₂ therapy, elevate HOB |
| **Acute Coronary Syndrome** | MONA (Morphine, O₂, Nitro, Aspirin), ECG monitoring, PCI prep |
| **Arrhythmias** | ECG interpretation, antiarrhythmics, pacemaker/ICD care |
| **Shock** | Fluid resuscitation, vasopressors, monitor perfusion (MAP ≥ 65) |
| **DVT/PE** | Anticoagulation, SCDs, early ambulation, leg elevation |

### 1.2 Respiratory (ระบบหายใจ)

| Condition | Key Nursing Care |
|---|---|
| **COPD** | Pursed-lip breathing, O₂ at 1-2 L/min (careful with CO₂ retainers), pulmonary rehab |
| **Asthma** | Peak flow monitoring, inhaler technique, trigger avoidance |
| **Pneumonia** | Antibiotics, O₂ therapy, chest physio, hydration, sputum culture |
| **Tuberculosis (วัณโรค)** | Airborne precautions, DOT (Directly Observed Therapy), 6-month regimen |
| **ARDS** | Mechanical ventilation, prone positioning, sedation management |

### 1.3 Gastrointestinal (ระบบทางเดินอาหาร)

| Condition | Key Nursing Care |
|---|---|
| **GI Bleeding** | NPO, IV fluids, NG lavage, monitor Hct, blood transfusion prep |
| **Liver Cirrhosis** | Low-Na⁺ diet, daily weight, monitor for ascites/varices/encephalopathy |
| **Pancreatitis** | NPO, IV fluids, pain management, NG to suction |
| **Bowel Obstruction** | NPO, NG decompression, monitor bowel sounds, surgical prep |
| **Appendicitis/Cholecystitis** | Pre/post-op care, pain management |

### 1.4 Renal & Urinary (ระบบขับถ่ายปัสสาวะ)

| Condition | Key Nursing Care |
|---|---|
| **Acute Kidney Injury (AKI)** | Strict I/O, daily weight, monitor BUN/Cr/K⁺, fluid/diuretic management |
| **Chronic Kidney Disease (CKD)** | Renal diet (low K⁺, low P, low Na⁺), dialysis access care, ESA therapy |
| **UTI** | Hydration, antibiotics, perineal care, cranberry (controversial) |
| **Renal Calculi** | Pain management, strain urine, increase fluids to 2-3 L/day |

### 1.5 Endocrine (ระบบต่อมไร้ท่อ)

| Condition | Key Nursing Care |
|---|---|
| **Diabetes Mellitus (เบาหวาน)** | BG monitoring, insulin administration, foot care, hypoglycemia management |
| **DKA / HHS** | IV insulin, fluid replacement, hourly BG, monitor K⁺ |
| **Thyroid disorders** | Thyroid storm (cooling, beta-blockers), myxedema coma (thyroxine, warming) |

### 1.6 Neurological (ระบบประสาท)

| Condition | Key Nursing Care |
|---|---|
| **Stroke (โรคหลอดเลือดสมอง)** | NIHSS assessment, tPA window (4.5 hrs), aspiration precautions, early rehab |
| **Seizure** | Seizure precautions (padded rails, suction ready), post-ictal care |
| **Meningitis** | Droplet precautions, antibiotics, ICP monitoring |
| **Increased ICP** | HOB 30°, hyperventilation (short-term), mannitol |

### 1.7 Musculoskeletal & Integumentary

| Condition | Key Nursing Care |
|---|---|
| **Fracture** | Neurovascular checks (5Ps: Pain, Pallor, Pulselessness, Paresthesia, Paralysis) |
| **Osteoarthritis** | Pain management, joint protection, PT referral |
| **Burns** | Fluid resuscitation, infection prevention, pain, nutrition (hypermetabolic state) |
| **Cellulitis** | Antibiotics, elevate limb, mark border, warm compress |

## 2 | Perioperative Nursing (การพยาบาลผู้ป่วยผ่าตัด)

### 2.1 Preoperative Phase

| Activity | Purpose |
|---|---|
| **Informed consent** | Verify signed, patient understands procedure |
| **NPO status** | Usually NPO after midnight (6-8 hrs) |
| **Pre-op checklist** | Allergies, meds, labs, imaging, bowel prep, skin prep |
| **Baseline vitals** | For comparison during/after surgery |
| **Patient education** | Deep breathing/coughing, incentive spirometry, pain expectations |

### 2.2 Intraoperative Phase

- **Scrub nurse** — Sterile field, instrument management
- **Circulating nurse** — Non-sterile support, documentation, counts
- **Positioning** — Prevent nerve injury, pressure points
- **Safety** — Time out, surgical site marking, counts (sponges, sharps, instruments)

### 2.3 Postoperative Phase

| Complication | Prevention/Monitoring |
|---|---|
| **Airway obstruction** | Recovery position, O₂, suction |
| **Hemorrhage** | Monitor VS, dressing, drains (Hemovac, Jackson-Pratt) |
| **DVT/PE** | SCDs, early ambulation, anticoagulation |
| **Infection** | Aseptic wound care, monitor temp/WBC |
| **Urinary retention** | Assess bladder, I/O, straight cath if needed |
| **Paralytic ileus** | NPO → clear → soft → regular diet as tolerated |

## 3 | Emergency & Critical Care Basics

| Emergency | Immediate Actions |
|---|---|
| **Cardiac arrest** | BLS: CAB (Circulation-Airway-Breathing), call code, start CPR |
| **Anaphylaxis** | Epinephrine IM (1:1000), O₂, IV fluids, antihistamines |
| **Hypoglycemia** | If conscious: 15g fast sugar; if unconscious: D50W IV or glucagon IM |
| **Sepsis** | Blood cultures, lactate, antibiotics within 1 hr, fluids (Sepsis Six bundle) |
| **Major trauma** | Primary survey: ABCDE (Airway, Breathing, Circulation, Disability, Exposure) |

## 4 | Key Terminology

| Thai | English | Notes |
|---|---|---|
| อายุรศาสตร์ | Medicine (Internal Medicine) | Non-surgical disease management |
| ศัลยศาสตร์ | Surgery | Operative treatment |
| การพยาบาลก่อนผ่าตัด | Preoperative Nursing | Preparation for surgery |
| การพยาบาลหลังผ่าตัด | Postoperative Nursing | Recovery and complication prevention |
| การติดเชื้อในโรงพยาบาล | Hospital-Acquired Infection (HAI) | Nosocomial infection |
| การช่วยฟื้นคืนชีพ | CPR (Cardiopulmonary Resuscitation) | BLS/ACLS |
| การใช้เครื่องช่วยหายใจ | Mechanical Ventilation | Ventilator management |
| สัญญาณชีพจร | Vital Signs Monitoring | Continuous vs. intermittent |
| แผลกดทับ | Pressure Injury | Prevention and staging |
| ภาวะติดเชื้อในกระแสเลือด | Sepsis | Life-threatening organ dysfunction |
