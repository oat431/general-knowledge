# 04 — Electrical & Computer Engineering

> *"Electrical engineers power the world. Computer engineers give it intelligence."*

These two fields are at the heart of everything modern — from the power grid to your smartphone. Thailand's growing tech sector, EV industry, and data center boom make these among the most dynamic engineering careers.

---

## Part A: Electrical Engineering (วิศวกรรมไฟฟ้า)

### 1 | Sub-Disciplines

#### 1.1 Power Systems (ไฟฟ้ากำลัง)

> **⚠️ Power systems engineering is a CONTROLLED field in Thailand.** You must be licensed to design building electrical systems, substations, and power distribution.

| Topic | Key Concepts |
|---|---|
| **Circuit Analysis** | DC/AC circuits, phasors, three-phase, complex power (P, Q, S), power factor |
| **Electromagnetics** | Maxwell's equations, transmission lines, wave propagation |
| **Power Generation** | Thermal (coal/gas), hydro, nuclear, solar, wind, biomass — generation mix |
| **Transmission & Distribution** | High-voltage transmission, substations, transformers, distribution feeders |
| **Power Electronics** | Converters (AC-DC, DC-DC, DC-AC), inverters, rectifiers — critical for renewables and EVs |
| **Electrical Machines** | Motors (DC, induction, synchronous), generators, transformers |
| **Protection Systems** | Relays, circuit breakers, grounding, lightning protection |
| **Smart Grid** | AMI (smart meters), demand response, distributed generation integration |

**Thai context:** EGAT (การไฟฟ้าฝ่ายผลิต), MEA (การไฟฟ้านครหลวง), and PEA (การไฟฟ้าส่วนภูมิภาค) are major employers. Thailand's PDP (Power Development Plan) targets 50% renewable energy.

#### 1.2 Electronics (วิศวกรรมอิเล็กทรอนิกส์)

| Topic | Key Concepts |
|---|---|
| **Analog Electronics** | Diodes, BJTs, MOSFETs, op-amps, amplifiers, filters, oscillators |
| **Digital Electronics** | Logic gates, flip-flops, counters, state machines, FPGA, VHDL/Verilog |
| **Microcontrollers & Embedded** | Arduino, ESP32, ARM Cortex, STM32, PIC — C programming |
| **Signal Processing** | Fourier analysis, filter design (FIR, IIR), DSP chips |
| **PCB Design** | Schematic capture, layout, EMC considerations, manufacturing |

#### 1.3 Telecommunications (วิศวกรรมโทรคมนาคม)

| Topic | Key Concepts |
|---|---|
| **Communication Theory** | Modulation (AM, FM, PM, QAM), multiplexing (FDM, TDM, OFDM), Shannon's theorem |
| **Wireless** | Antennas, propagation, cellular (2G→5G), WiFi, Bluetooth, LoRa, satellite |
| **Optical Fiber** | Single-mode, multi-mode, DWDM, optical amplifiers |
| **Networking** | TCP/IP, routing (OSPF, BGP), switching, MPLS, SDN |

**Thai context:** 5G rollout; True, AIS, dtac are major telecom employers. Growing data center industry.

#### 1.4 Control & Automation

| Topic | Key Concepts |
|---|---|
| **Classical Control** | Transfer functions, stability (Routh-Hurwitz, Bode, Nyquist), PID tuning |
| **Modern Control** | State-space, observers, optimal control (LQR), robust control |
| **PLC & SCADA** | Ladder logic, HMI, industrial networks (Modbus, Profibus, Ethernet/IP) |
| **Robotics** | Kinematics, trajectory planning, sensors, actuators |

## Part B: Computer Engineering (วิศวกรรมคอมพิวเตอร์)

### 2 | Core Areas

#### 2.1 Computer Architecture

| Topic | Key Concepts |
|---|---|
| **Digital Logic Design** | Combinational + sequential circuits, ALU, datapath, control unit |
| **Processor Architecture** | ISA, pipelining, superscalar, out-of-order execution, RISC vs. CISC |
| **Memory Hierarchy** | Cache (L1/L2/L3), DRAM, virtual memory, TLB |
| **Embedded Systems** | ARM, RISC-V, real-time OS (FreeRTOS), IoT devices |

#### 2.2 Software & Systems

| Topic | Key Concepts |
|---|---|
| **Programming** | C, C++, Python, Java, Rust |
| **Data Structures & Algorithms** | Arrays, linked lists, trees, graphs, sorting, searching, complexity |
| **Operating Systems** | Processes, threads, scheduling, memory management, file systems, Linux |
| **Computer Networks** | TCP/IP stack, HTTP, DNS, TLS, socket programming |
| **Databases** | SQL, NoSQL, normalization, transactions |
| **Software Engineering** | Version control (Git), testing, CI/CD, Agile |

#### 2.3 Emerging: AI & Machine Learning Hardware

| Topic | Application |
|---|---|
| **GPU Computing** | CUDA, parallel processing for ML training |
| **Edge AI** | ML inference on embedded devices (TensorFlow Lite, ONNX) |
| **FPGA for AI** | Custom accelerators, low-latency inference |
| **Neuromorphic Computing** | Brain-inspired chips — research frontier |

## 3 | Career Outlook — Electrical & Computer in Thailand

### Electrical

| Sector | Demand | Key Employers |
|---|---|---|
| **Power & Utilities** | Stable | EGAT, MEA, PEA, renewable energy firms |
| **Building Services (M&E)** | 🔥 HIGH | Consultants, contractors (controlled field = licensed EEs in demand) |
| **Electronics Manufacturing** | 🔥 HIGH | Western Digital, Seagate, Sony, Samsung, Delta Electronics, Fabrinet |
| **Telecom** | Moderate | True, AIS, dtac, NT (National Telecom) |
| **EV Industry** | 🔥 EMERGING | Chinese EV makers (BYD, MG, Great Wall), charging infrastructure |

### Computer

| Sector | Demand | Key Employers |
|---|---|---|
| **Software / Tech** | 🔥 VERY HIGH | Agoda, LINE, Shopee, Lazada, Ascend, startups |
| **Semiconductor** | 🔥 HIGH | Microchip, ON Semi, Analog Devices, Western Digital |
| **Embedded / IoT** | 🔥 HIGH | Delta, Fabrinet, automotive suppliers |
| **Data Center** | 🔥 EMERGING | AWS (planned), True IDC, CSL |
| **FinTech** | 🔥 HIGH | SCB, KBank, KBTG, Ascend Money, Opn |
| **Cybersecurity** | 🔥 VERY HIGH | Government, banking, all enterprises |

**Starting salary:** ฿25,000–฿45,000 (software/tech), ฿22,000–฿35,000 (power/hardware)
