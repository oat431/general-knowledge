# English for Technology — ภาษาอังกฤษกับเทคโนโลยี

> *"Almost every interface, error message, tutorial, and line of code a Thai student will ever use is in English. Technology makes English unavoidable."*

Standard อ 3.1 connects English to technology and computing: device vocabulary early, then software and internet language, and by ม.ปลาย the working English of coding basics, AI tools, and online learning. For Thai students this is the strand with the highest real-world payoff — the digital world runs on English, and tech vocabulary is absorbed daily whether or not the classroom teaches it.

## 1 | Grade Band Breakdown

| Grade | Key Content |
|---|---|
| **ม.1–3** | Devices and apps vocabulary, using browsers and search in English, typing and documents, internet safety language, reading simple tech instructions |
| **ม.4–6** | Coding basics vocabulary (variable, loop, function, debug), software and hardware terms, online communication tools, AI assistants and prompt basics, tech news reading |

*Primary years touch technology vocabulary through computer-games and drawing apps, but the curriculum concentrates this strand in secondary.*

## 2 | The Technology Vocabulary Core

| Domain | Key terms | Bands |
|---|---|---|
| Devices | computer, laptop, tablet, charger, screen, keyboard | ม.1–ม.3 |
| Internet | browser, search, website, download, upload, password, Wi-Fi | ม.1–ม.3 |
| Software | install, update, save, file, folder, attachment, account | ม.1–ม.6 |
| Coding | program, code, variable, loop, function, bug, debug, run | ม.4–ม.6 |
| AI and online tools | chatbot, prompt, generate, translate, search engine, cloud | ม.4–ม.6 |

## 3 | Language Patterns for Technology

| Function | Pattern | Example |
|---|---|---|
| Instructions | imperative steps | **Click** the icon, **select** Settings, **choose** Language. |
| Describing problems | doesn't work / won't + verb / error + ing | The app **won't load**. I keep **getting** an error message. |
| Asking for help politely | Could you show me how to...? | **Could you show me how to** attach a file? |
| Explaining what code does | This function takes ... and returns ... | This loop **counts from 1 to 10 and prints** each number. |
| Talking about AI tools | use X to + verb | I use a chatbot **to practice** conversation English. |

## 4 | English as the Interface Language

| Situation | What the student meets |
|---|---|
| Phone and app settings | English menus even on Thai phones |
| Error messages | "Connection timed out," "File not found" |
| Tutorials | YouTube and documentation overwhelmingly in English |
| Programming languages | Keywords are English: `if`, `for`, `while`, `return` |
| Online courses | MOOCs, Khan Academy, Coursera — English-first |
| AI assistants | Prompts in English often give richer results |

## 6 | Common Errors

| Error | Example | Fix |
|---|---|---|
| Thai-English tech mixing | "แชร์ link ให้ download ไฟล์" in formal writing | Keep formal writing in full English → [[31 Register & Formality]] |
| Verb+noun errors | "open the TV", "on the light" | turn on/off the TV and lights |
| Countable confusion | "a softwares", "many informations" | software and information are uncountable → [[04 Countable vs Uncountable Nouns]] |
| Preposition gaps | "search in Google" | search (the web) **for** / search **on** Google → [[20 Prepositions]] |
